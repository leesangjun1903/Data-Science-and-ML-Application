# Discovery of a structural class of antibiotics with explainable deep learning

### 1. 핵심 주장과 주요 기여 요약

이 논문의 핵심 주장은 **그래프 신경망(Graph Neural Network, GNN)을 기반으로 하는 설명 가능한 딥러닝 접근법**이 항생제 신약 개발에서 구조적 신규성(structural novelty)을 갖춘 화합물 클래스를 효율적으로 발견할 수 있다는 것입니다.[1]

주요 기여는 다음과 같습니다:[1]

- **설명 가능성(Explainability)의 구현**: 전통적인 블랙박스 딥러닝 모델을 벗어나 그래프 기반의 부분구조(substructure) 설명을 통해 모델의 의사결정 과정을 해석 가능하게 제시했습니다.

- **항생제 신규 구조 클래스 발견**: 12,076,365개의 화합물 라이브러리를 스크리닝하여 메티실린 내성 황색포도상구균(MRSA)과 반코마이신 내성 장구균(VRE)에 대해 활성을 지니는 새로운 구조 클래스(화합물 1, 2)를 발견했습니다.

- **임상적 유효성 입증**: 마우스 감염 모델에서 국소 도포 및 전신 치료 모두에서 유효성을 입증하여 AI 기반 신약 발견의 실질적 가치를 증명했습니다.

### 2. 문제 정의, 제안 방법론, 모델 구조 및 성능

#### 2.1 해결하고자 하는 문제

항생제 내성의 확산으로 인해 **새로운 항생제 구조 클래스의 발견이 시급한 상황**입니다. 기존의 고전적인 약물 발견 방법은 비용이 높고 시간이 오래 걸리며 성공률이 낮다는 문제가 있습니다. 특히 알려진 구조 모티프(scaffold)에 의존하는 QSAR(Quantitative Structure-Activity Relationship) 분석은 신규 구조 발견에 한계가 있습니다.[1]

#### 2.2 제안 방법론 및 수식

**그래프 신경망 기반 메시지 패싱(Message Passing)**

각 화합물을 원자(atom)를 정점(vertex)으로, 화학 결합(bond)을 간선(edge)으로 하는 그래프로 표현합니다. 모델의 핵심 연산은 다음 수식으로 표현됩니다:[1]

각 결합 $$b$$에 대한 메시지는 다음과 같이 업데이트됩니다:

$$m_b^{(t+1)} = \text{NN}\left(m_b^{(t)} \oplus \sum_{b' \in N(b)} m_{b'}^{(t)}\right)$$

여기서:
- $$m_b^{(t)}$$는 시간 단계 $$t$$에서 결합 $$b$$의 메시지
- $$N(b)$$는 결합 $$b$$의 이웃 결합들의 집합
- NN은 비선형 활성화 함수를 가진 신경망 계층
- $$\oplus$$는 연결(concatenation) 연산

고정된 메시지 패싱 단계 후, 분자 전체의 메시지를 합산하여 최종 표현을 생성합니다:

```math
\text{mol\_message} = \sum_{b \in \text{bonds}} m_b^{(T)}
```

이를 피드포워드 신경망에 입력하여 예측값을 생성합니다:

```math
\hat{y} = \text{FFN}(\text{mol\_message})
```

항생제 활성 예측의 경우, 최종 출력은 0~1 사이의 확률값으로 표현됩니다.

**모델 최적화 전략**

세 가지 최적화 전략을 적용했습니다:[1]

1. **RDKit 특성 추가**: 200개의 분자 수준 특성(예: 수소 결합 공여자/수용자 수, 분할계수)을 그래프 표현에 추가하여 메시지 패싱으로 캡처하지 못하는 전역 특성을 제공합니다.

2. **하이퍼파라미터 최적화**: 제한된 그리드 서치를 통해 각 모델의 최적 하이퍼파라미터를 선정합니다.

3. **앙상블 방식**: 20개의 독립적으로 훈련된 모델의 예측을 평균하여 견고성을 증가시킵니다.

$$\hat{y}_{\text{ensemble}} = \frac{1}{20}\sum_{i=1}^{20} \hat{y}_i$$

#### 2.3 몬테카를로 트리 서치(MCTS)를 통한 설명 가능성 추출

**MCTS 알고리즘의 핵심**[1]

분자의 설명(rationale)을 찾기 위해 MCTS를 사용합니다. 각 상태 $$S$$는 다음 통계를 저장합니다:

- $$N_S$$: 상태 $$S$$가 방문된 횟수 (탐험-활용 균형 제어)
- $$W_S$$: 총 장기 보상 (상태 $$S$$에서 유효한 설명으로 도달할 가능성)
- $$R_S$$: 상태 $$S$$의 예측 활성 점수 (즉각적 보상)

**전진 패스(Forward Pass)**에서 각 중간 상태 $$S$$에서 삭제 행동 선택 기준:[1]

$$\text{action}_S = \arg\max_{s \in S_{\text{child}}} \left(W_s + c_s \sqrt{\frac{\ln N_s}{N_s}}\right)$$

여기서 $$c_s$$는 PUCT(Predictor Upper Confidence Bound applied to Trees) 식에 따라 설정됩니다.

**역진 패스(Backward Pass)**에서 통계 업데이트:[1]

$$N_S \leftarrow N_S + 1$$
$$W_S \leftarrow W_S + R_{S_{\text{leaf}}}$$

### 2.4 모델 성능

**항생제 활성 예측**[1]

- **훈련 데이터**: 39,312개 화합물 스크린, 활성 512개(1.3%)
- **정밀도-재현율 곡선(AUPRC)**: 0.364 (95% CI: 0.359-0.379)
- **AUROC**: 우수한 성능 입증

**독성 예측 모델**[1]

| 세포 유형 | AUPRC | AUROC |
|----------|-------|-------|
| HepG2 (간암) | 0.176 | 낮음 |
| HSkMC (골격근) | 0.168 | 낮음 |
| IMR-90 (폐섬유아) | 0.335 | 비교적 우수 |

항생제 활성 모델 성능이 독성 모델보다 우수한 이유는 항생제 데이터 불균형이 더 심하기 때문입니다(1.3% vs. 3.8-8.8%).

**설명 가능성 검증**[1]

- MCTS를 통해 1,261개의 신규 구조 화합물 중 186개(14.8%)에서 설명 가능한 부분구조(최소 8개 원자) 추출
- 5개의 구별되는 스캐폴드(G1-G5) 식별
- 실험적 검증: G1-G5 관련 9개 화합물 중 4개(44%) 활성 확인

### 2.5 임상 성능 및 한계

**우수한 선택도(Selectivity)와 효능**[1]

화합물 1, 2는 다음과 같은 특성을 보였습니다:

- **최소 억제 농도(MIC)**: 0.5-2 μg/mL (S. aureus)
- **세포 독성 IC50**: ≥128 μg/mL (모든 인간 세포 유형)
- **선택도**: 최소 64배 이상 (세포 독성 IC50 / 항생제 MIC)
- **혈청 안정성**: 10% FBS 포함 배지에서 MIC 4-8배 증가하지만 여전히 인간 세포 IC50보다 8배 이상 낮음

**한계점**[1]

1. **독성 모델 성능 제한**: 독성 예측의 낮은 AUPRC로 인해 거짓 양성이 발생할 수 있음
2. **그람 음성균 활성 부재**: 현재 모델은 그람 양성균(S. aureus, 장구균)에만 활성
3. **화학적 다양성 제약**: 구매 가능한 화합물 데이터베이스(M-cule)에 제한되어 전체 화학 공간의 극히 일부만 탐색
4. **저항성 진화 가능성**: 30일 연속 계대 배양에서 MIC 변화는 없었으나 장기 임상 사용 시 저항성 발생 가능

### 3. 모델의 일반화 성능 향상 가능성

#### 3.1 현재 일반화 능력

**화학 공간 일반화**[1]

- t-SNE 분석 결과, 예측된 활성 화합물이 훈련 세트와 화학적으로 구별됨을 보여줍니다.
- 구조적 신규성 필터(Tanimoto 유사도 < 0.5)를 통과한 화합물 1,261개 중 20%가 실험적으로 검증되었으며, 8.7%의 실제 긍정 발견률(Working True Discovery Rate)을 달성했습니다. 이는 훈련 데이터의 1.3% 활성률보다 훨씬 높습니다.

**클래스 외(Out-of-Distribution) 일반화 테스트**[1]

Leave-one-out 분석:
- 퀴놀론(quinolone) 클래스 제외 훈련 후 예측: 참 양성률 0.294
- 베타-락탐(β-lactam) 클래스 제외 훈련 후 예측: 참 양성률 0.060

이는 모델이 알려지지 않은 구조 클래스도 어느 정도 일반화할 수 있음을 시사합니다.

#### 3.2 일반화 성능 향상을 위한 전략

**데이터 다양성 확대**[1]

논문에서 제시된 반복적 접근법:

$$\text{일반화 성능 향상} = f(\text{신규 데이터 생성}, \text{모델 재훈련}, \text{부분구조 식별})$$

저자들은 다음을 제안합니다:
- 신규 화합물 테스트 데이터를 훈련 데이터에 추가
- 모델 재훈련 및 새로운 부분구조 식별
- 이 과정의 반복적 수행으로 더욱 완전한 화학 공간 표현 구성

**혼합 모델 접근법**

최근 연구는 조건부 생성 모델(VAE, GAN)과 GNN 평가 모델을 결합하여 이전에 열거되지 않은 화학 공간 탐색을 제안하고 있습니다.[2]

**도메인 적응(Domain Adaptation)**

그람 음성균에 대한 활성 확보를 위해:[1]

- 투과성(permeability)을 명시적으로 예측하는 추가 모델 훈련
- 외막 투과성(outer membrane permeability) 관련 특성 추가
- 다중 목표 최적화를 통한 선택도-활성 균형 달성

#### 3.3 제약 및 개선 방향

**현재 제약**[1]

1. **데이터 불균형**: 활성 화합물이 1.3%에 불과하여 적절한 신호 학습 제한
2. **평가 메트릭 의존성**: AUPRC 기반 평가로 인한 임계값 설정의 자의성
3. **메커니즘 이해 부족**: 부분구조가 활성을 유도하는 메커니즘의 직접적인 설명 부족

**개선 방향**[1]

- 더 정교한 부분구조 분석을 위한 입력 교란(input perturbation) 기반 설명 가능성 방법 개발
- 신경망 구조 교란을 통한 해석 가능성 향상
- 단백질 결합(protein binding) 포함한 더욱 상세한 화학 공간 표현

### 4. 향후 연구에 미치는 영향 및 고려사항

#### 4.1 현재 AI 신약 발견 분야 현황

최신 연구에 따르면, AI/ML 기반 신약 발견은 다음과 같은 단계에 있습니다:[3][4][5]

**생성 모델의 발전**

최근 2025년 발표된 연구에서는 조건부 생성 모델(variational autoencoder, generative adversarial network)과 유전 알고리즘을 결합하여:[2]
- 45백만 개의 화학 단편을 스크린하거나 완전 신규 화합물 생성
- 24개 화합물 합성 중 7개(29%) 항생제 활성 확인
- 2개 화합물이 다제내성(MDR) 균주에 대해 고유 작용 메커니즘 보유

이는 본 논문의 단순 스크리닝 접근법보다 더욱 광범위한 화학 공간 탐색을 가능하게 합니다.

**설명 가능 AI의 중요성**

2024-2025년 최신 리뷰에서 강조되는 핵심 주제:[6][7][8]

1. **규제 승인**: XAI는 임상 승인을 위한 필수 요구사항
2. **신뢰도 구축**: 모델 투명성을 통한 화학자/약학자의 신뢰 획득
3. **최적화 지향**: 의사결정 기반 제공

#### 4.2 앞으로의 연구 고려사항

**1. 다중 타겟 최적화**[1]

그람 음성균 대상 항생제 개발을 위해서는:

$$\text{목적함수} = \alpha \cdot \text{활성} + \beta \cdot \text{선택도} + \gamma \cdot \text{투과성} - \delta \cdot \text{독성}$$

여기서 $$\alpha, \beta, \gamma, \delta$$는 가중치 파라미터입니다.

**2. 데이터 취득 전략**

- **수동적 반복 학습**: 신규 화합물 테스트 → 데이터 축적 → 모델 재훈련
- **능동적 학습**: 불확실성이 높은 화합물을 우선적으로 테스트하여 학습 효율성 향상

**3. 메커니즘 기반 모델 개발**[9]

최근 연구에서 제시되는 방향:
- 작용 메커니즘 예측 모델 개발 (예: 양성자 동력(proton motive force) 교란)
- 세포 생리학적 프로파일링과 AI 결합
- 구조-활성 관계(SAR) 공간의 평탄성 이해

**4. 전산 화학과 실험의 통합**[4]

자체 주도 실험실(Self-Driving Labs):
- AI가 실험 설계 및 실행 자동화
- 고속 피드백 루프로 모델 개선
- 비용 및 시간 절감

**5. 다종 데이터 통합**

최신 트렌드:[5][3]
- **자연어 처리(NLP)**: 문헌 데이터에서 약물-표적 상호작용 추출
- **구조 생물학**: AlphaFold 예측 단백질 구조 활용
- **게놈학**: 박테리아 유전체 데이터로 저항성 메커니즘 이해

#### 4.3 한계 및 미충족 필요

**구조 기반 제약**[5][1]

현재 접근법의 한계:
- 구매 가능 화합물 DB(M-cule: 11,277,225개)는 전체 약물 유사 화학 공간의 극히 일부 (전체 추정 $$10^{60}$$ 화합물)
- 합성 가능성(synthesizability) 고려 미흡
- 대사 안정성, 약동학(ADMET)의 정확한 예측 부족

**생물학적 정밀성**[3][4]

- 단순 활성 여부 예측 → 작용 메커니즘, 약효 반응까지 확장 필요
- 비특이적 독성(off-target toxicity) 예측 정확도 향상 필수
- 임상 단계 실패의 주요 원인인 약동학 특성 개선

**규제 및 윤리**

- FDA/EMA 승인을 위한 AI 모델 검증 표준화 미흡
- AI 생성 화합물의 지적 재산권 문제
- 항생제 과다 개발로 인한 환경 오염 우려

#### 4.4 시사점

**학문적 기여**

본 논문은 설명 가능한 AI가 신약 발견에서 "탐색 효율성"과 "신규성" 사이의 균형을 제공할 수 있음을 입증했습니다. MCTS 기반 부분구조 설명 방법은 향후 다른 약물 발견 영역(항바이러스제, 항암제)에도 적용 가능합니다.

## 결론

"Discovery of a structural class of antibiotics with explainable deep learning"은 **검은 상자 모델의 설명 가능성 문제를 해결하면서 동시에 항생제 신규 구조 발견의 실질적 성과를 달성한 획기적 연구**입니다. MCTS 기반 설명 추출, 구조적 신규성 강조, 임상 효능 입증을 통해 AI가 단순한 스크리닝 도구를 넘어 **창의적 신약 설계의 파트너**가 될 수 있음을 보여주었습니다.[1]

향후 연구에서는 (1) 생성 모델을 통한 광범위한 화학 공간 탐색, (2) 다중 작용 메커니즘 동시 최적화, (3) 실시간 임상 데이터 피드백 시스템 구축이 중점되어야 할 것으로 예상됩니다.

# Spiking Deep Residual Network

### 1. 핵심 주장 및 주요 기여

**Spiking Deep Residual Network** 논문의 핵심 주장은 **심층 신경망 구조를 유지하면서 에너지 효율적인 스파이킹 신경망(SNN)을 구축할 수 있다**는 점입니다. 이 논문의 주요 기여는 다음과 같습니다:[1]

첫째, **Residual Network의 스파이킹 버전 변환**에 성공했습니다. 기존의 선형 구조의 신경망 변환 방식이 ResNet의 잔차 구조(shortcut)에 적용될 수 없었기 때문에, 이를 해결하기 위한 새로운 변환 모델을 제안했습니다.

둘째, **스파이킹 신경망의 깊이 제한을 극복**했습니다. 종전에는 30층 이상의 깊은 SNN 구축이 불가능했지만, 이 논문에서는 최초로 40층을 초과하는 깊은 SNN을 대규모 데이터셋에서 구현했습니다.[1]

셋째, **신경망 크기 확장성 문제를 해결**했습니다. MNIST, CIFAR-10, CIFAR-100, ImageNet 2012 등 다양한 벤치마크에서 기존 최고 성능의 SNN 방식들을 능가하는 성능을 달성했습니다.[1]

### 2. 해결 문제 및 제안 방법

#### 2.1 해결하고자 하는 문제

SNN 훈련의 핵심 도전 과제는 **이산 이벤트 기반 스파이킹 메커니즘의 비미분 특성**(non-differentiability)입니다. 이로 인해:[1]

- 전통적 역전파 알고리즘의 직접 적용이 불가능
- 깊은 신경망 구조 구현의 어려움
- 신경망 깊이 증가에 따른 성능 급락

#### 2.2 제안된 방법

**ANN-to-SNN 변환 접근법**을 채택했습니다. 이는 다음 단계로 구성됩니다:

**Step 1: 기본 정규화**

ANN의 활성화 값을 SNN의 발화율(firing rate)에 매핑하기 위해 가중치와 편향을 정규화합니다:

$$W = \frac{\lambda_{l-1}}{\lambda_l} W, \quad b = \frac{1}{\lambda_l} b$$

여기서 $\lambda_l$은 계층 $l$의 최대 활성화값(99.9% 또는 99.99% 백분위수)입니다.[1]

배치 정규화 계층의 가중치와 편향은 다음과 같이 스케일됩니다:

$$\tilde{W} = \frac{\gamma W}{\sigma}, \quad \tilde{b} = \frac{\gamma(b - \mu)}{\sigma} + \beta$$[1]

**Step 2: 잔차 구조 변환 모델**

기본 잔차 블록의 원래 출력은:

$$y = W_2(W_1 X + b_1) + b_2 + X$$[1]

정규화된 가중치와 편향을 적용한 후, 정규화된 출력은:

$$y_{norm} = \frac{y}{max_{out}} = \frac{W_2(W_1 X + b_1) + b_2 + X}{max_{out}}$$[1]

정규화 일관성을 유지하기 위해 **shortcut 가중치를 다음과 같이 스케일**합니다:

$$\lambda = \frac{max_{in}}{max_{out}}$$[1]

이 변환 모델은 shortcut 연결에서 $\lambda$만큼 곱해져 다음과 같이 표현됩니다:

$$y' = W_2(W_1 X' + b_1) + b_2 + \frac{1}{max_{in}} X$$[1]

**Step 3: 전파 오류 보상**

IF 뉴런의 발화율과 ReLU 활성화 간의 근사 오차가 신경망 깊이에 따라 누적되는 문제를 해결합니다.

ReLU 활성화와 발화율의 관계식에서 전파 오류 $E_i(t) = \frac{V_i(t)}{t}$가 누적됨을 도출합니다:[1]

$$r_i(t) = a_i - E_i$$

실험적 관찰을 통해 오류의 누적 패턴을 지수 모델로 근사합니다:

$$E_l = p \cdot q^l$$[1]

여기서 $p$와 $q$는 상수이고 $l$은 신경망 깊이입니다.

이 모델을 기반으로 보상 인자 $\zeta$를 도입하여 가중치를 조정합니다:

$$W' = W \cdot \zeta$$[1]

$\zeta$는 학습 데이터의 부분 집합으로 $q$ 근처에서 단계적으로 탐색되며, 범위는 $(1, \tau_{max})$로 제한됩니다. 여기서 $\tau_{max}$는 마지막 계층의 최대 발화율의 역수입니다.[1]

### 3. 모델 구조

#### 3.1 전체 변환 아키텍처

ResNet의 각 구성 요소는 다음과 같이 변환됩니다:[1]

| ANN 구성 | SNN 구성 | 역할 |
|---------|---------|------|
| ReLU 활성화 | Integrate-and-Fire (IF) 뉴런 | 비선형 처리 |
| 합산 계층 | IF 뉴런 통합 | 임묵적 덧셈 |
| 합성곱 계층 | 시냅스 연결 (가중치 매핑) | 피처 추출 |
| 편향 | 상수 전류 주입 | 신경 자극 |
| 평균 풀링 | 시냅스 가중치 1/PoolSize² | 공간 축소 |
| 최대 풀링 | 논리 비교 (최고 발화율 선택) | 특성 선택 |

#### 3.2 신경망 깊이별 구현

논문에서 구현된 S-ResNet의 깊이는 CIFAR-10에서 20, 32, 44, 56, 110 계층이고, ImageNet에서는 18, 34, 50 계층입니다.[1]

### 4. 성능 향상 결과

#### 4.1 Shortcut 정규화의 효과

표 2에 제시된 결과에 따르면, shortcut을 정규화하지 않은 경우와 정규화한 경우의 오류율 차이는 상당합니다:[1]

- **ResNet-20**: 정규화 없음 10.55% → 정규화 있음 8.21% (2.34% 개선)
- **ResNet-44**: 정규화 없음 15.44% → 정규화 있음 8.02% (7.42% 개선)
- **ResNet-110**: 정규화 없음 20.77% → 정규화 있음 12.18% (8.59% 개선)

#### 4.2 오류 보상의 효과

CIFAR-10에서 오류 보상 메커니즘을 적용한 결과:[1]

**ResNet의 경우:**
- S-ResNet-20: 8.21% → 8.18% (0.03% 개선, $E$: 0.004226 → 0.004068)
- S-ResNet-44: 8.02% → 7.63% (0.39% 개선, $E$: 0.006351 → 0.005476)

**일반 CNN (VGG 유사)의 경우 더 큰 개선:**
- S-CNN-20: 11.26% → 10.60% (0.66% 개선)
- S-CNN-32: 15.82% → 13.88% (1.94% 개선)

#### 4.3 대규모 데이터셋 성능

**ImageNet 2012 결과:**[1]

| 깊이 | ResNet | S-ResNet | S-ResNet (보상) | 정확도 손실 |
|------|--------|----------|-----------------|-----------|
| ResNet-18 | 30.79% (Top-1) | 31.65% | 31.64% | 0.84% |
| ResNet-34 | 27.12% (Top-1) | 28.49% | 28.39% | 1.27% |
| ResNet-50 | 24.55% (Top-1) | 27.69% | 27.25% | 2.69% |

Top-5 오류의 경우 더 나은 성능을 보입니다:
- ResNet-50: 7.50% → 9.03% (1.52% 손실)

#### 4.4 타 방법과의 비교

CIFAR-10에서 최고의 성능을 달성했습니다:[1]

- S-ResNet-44: 7.63% 오류율 (0.48% 정확도 손실)
- 기존 최고 방법들 대비 우수한 성능 달성

### 5. 한계 및 과제

#### 5.1 깊이-성능 트레이드오프

깊이가 증가할수록 성능 손실이 증가하는 경향:[1]

- **깊이 18**: 0.84% 손실
- **깊이 50**: 2.69% 손실

이는 누적 전파 오류가 깊이에 따라 지수적으로 증가하기 때문입니다.

#### 5.2 시뮬레이션 시간 요구사항

SNN은 시간 단계별 시뮬레이션이 필요하여, 논문에서는 350 시간 단계를 사용했습니다. 이는 실시간 처리에 제약을 가합니다.

#### 5.3 정규화 매개변수의 민감성

최대 활성화값을 99.9% 또는 99.99% 백분위수로 사용하는데, 이 선택이 최적인지에 대한 검증이 제한적입니다.

#### 5.4 소규모 데이터셋에서의 제한

MNIST에서는 손실이 없지만(깊이 8), 일반적으로 깊은 네트워크에서는 성능 손실이 발생합니다.

### 6. 일반화 성능 향상 가능성

#### 6.1 일반화 성능 분석

논문의 S-ResNet은 **구조적 정규화 효과**를 통해 일반화 성능을 개선합니다:[1]

- **Residual 구조의 이점**: 잔차 연결은 깊은 네트워크에서 그래디언트 흐름을 개선하여 더 나은 일반화를 가능하게 합니다.

- **정규화 메커니즘**: 활성화 값과 발화율의 일관성 유지는 오버피팅을 감소시킵니다.

- **전파 오류 보상**: 깊은 계층에서의 오류를 체계적으로 보정하므로, 모델이 더 안정적인 특성 표현을 학습합니다.

#### 6.2 일반화 성능 개선 방향 (최신 연구 기반)

최근 연구에서 제시된 SNN의 일반화 성능 개선 방법들은 다음과 같습니다:[2][3][4]

**1) 시간적 정규화 (Temporal Regularization Training, TRT)**

시간 종속적 정규화 메커니즘을 도입하여 오버피팅을 줄입니다. 이 방법은 신경망의 시간적 역학을 활용하여 일반화 성능을 현저히 개선합니다. 실험 결과에 따르면 신경망 모델의 손실 경관(loss landscape)을 개선하고 오버피팅을 완화합니다.[4]

**2) 하이브리드 신경망 아키텍처**

ANN과 SNN을 결합한 하이브리드 접근법이 정확도와 효율성의 최적 균형을 제공합니다. 순차 처리 작업에서 SNN의 고유한 시간적 특성을 활용하는 연구가 활발합니다.[3]

**3) 신경원 모델의 개선**

기존의 포인트 뉴런 모델에서 벗어나 **수상돌기 스파이킹 뉴런(Dendritic Spiking Neuron, DendSN)**을 도입합니다. 이는 뇌 신경과학의 다중 구획 모델에서 영감을 얻어 네트워크 표현력을 크게 향상시킵니다. DendSN은 비선형 수상돌기 역학을 통해 더 높은 표현성을 제공하며, 재난적 망각(catastrophic forgetting)을 완화합니다.[5]

**4) 양자화 기법의 발전**

극저정밀 멤브레인 전위 양자화(SpQuant-SNN)는 가중치, 멤브레인 전위, 공간-채널 희소성을 모두 고도로 양자화하여, 에지 디바이스에서의 배포 가능성을 높입니다. 이는 메모리 오버헤드를 줄이면서도 일반화 성능을 유지합니다.[2]

**5) 주의 메커니즘(Attention Mechanism)**

생물학적으로 영감을 받은 주의 메커니즘 (BIASNN)은 스파이크 기반 인코딩 특성을 활용하여 분류 정확도를 향상시키고, 필요한 시간 단계를 최소화합니다.[6]

**6) 트랜스포머 기반 SNN**

트랜스포머 구조를 SNN에 적용한 최근 연구들은 대규모 데이터셋에서 우수한 일반화 성능을 달성하고 있습니다. 이러한 아키텍처는 장거리 의존성을 더 효과적으로 포착합니다.[7]

### 7. 향후 연구에 미치는 영향 및 고려사항

#### 7.1 연구 영향

**Spiking ResNet 논문은 SNN 분야에 다음과 같은 중요한 영향을 미쳤습니다:**

1. **심층 SNN 구축의 가능성 제시**: 40층 이상의 깊은 SNN을 대규모 데이터셋에서 구현할 수 있음을 증명했습니다. 이는 이후 연구자들에게 깊은 신경망 아키텍처 탐색의 새로운 방향을 제시했습니다.[1]

2. **변환 기반 학습의 체계화**: Residual 구조의 효과를 SNN 변환에 통합함으로써, 일반적인 ANN-to-SNN 변환 프레임워크의 한계를 극복했습니다. 이후 다양한 현대적 CNN 아키텍처(DenseNet, EfficientNet 등)의 변환 연구를 촉발했습니다.[1]

3. **신경망 깊이 확장의 실질적 해결책 제공**: 누적 전파 오류를 수학적으로 모델링하고 지수 함수로 근사한 후 체계적으로 보정하는 방법은 이후 연구의 표준이 되었습니다.[1]

#### 7.2 최신 연구의 발전 동향

논문 이후 SNN 연구 분야는 다음과 같은 방향으로 진화했습니다:[8][3][4][5][6][7][2]

**1) 직접 훈련 방법의 발전**

- **Surrogate Gradient 방법**: SNN의 불미분 스파이킹 함수를 근사하여 역전파를 가능하게 합니다. 최근 연구는 이를 개선하여 ANN에 가까운 정확도(1-2% 내 오류)를 달성합니다.[9]
- **신경망 깊이 확대**: 최신 연구에서는 수백 층 이상의 깊은 SNNs를 직접 훈련하고 있습니다.[9]

**2) 신경형 칩(Neuromorphic Hardware) 구현**

- **Intel Loihi 2**: 차세대 신경형 프로세서는 SNN의 에너지 효율성을 극대화합니다.
- **실제 배포**: 로봇 제어, 드론 비행, 로봇팔 제어 등 실제 애플리케이션에서 SNN 기반 시스템이 배포되고 있습니다.[8]

**3) 멀티모달 및 시계열 처리**

최신 연구는 텍스트, 음성, 시각 데이터를 포함한 다양한 입력 형식을 처리하는 SNN의 능력을 탐구하고 있으며, SNN이 RNN/LSTM 대비 더 효율적인 시계열 처리를 제공할 수 있음을 보여줍니다.[3]

**4) 대규모 모델 개발**

- **SpikeLM**: 스파이크 기반 언어 모델로, 일반적인 LLM 수준의 성능을 에너지 효율적으로 달성하는 방향을 탐구합니다.[10]
- **ImageNet 규모 SNNs**: 최근 연구는 ImageNet100 수준의 대규모 데이터셋에서 경쟁력 있는 SNN을 구축합니다.

#### 7.3 앞으로 연구 시 고려할 점

**1) 하드웨어-소프트웨어 코설계**

SNN의 이론적 우수성을 실제 에너지 절감으로 전환하기 위해서는 신경형 하드웨어와의 긴밀한 통합이 필수입니다. 종래의 CPU/GPU에서의 SNN 시뮬레이션은 계산상 이점을 상실합니다.[11]

**2) 정규화 기법의 개선**

- 적응형 정규화: 데이터셋별, 계층별 동적 정규화 방식 개발
- 동적 임계값 조정: 신경원 수준의 적응형 임계값 조정[9]

**3) 전이 학습(Transfer Learning) 프레임워크**

사전 훈련된 ANN 모델의 효과적인 SNN 변환을 위한 표준화된 프로토콜 개발이 필요합니다. 특히 ImageNet 사전 훈련 모델의 변환 방법론 확립이 중요합니다.

**4) 일반화 성능 이론**

- SNN의 VC 차원 또는 Rademacher 복잡도를 분석하여 일반화 경계를 유도
- 시간적 정규화가 일반화 오류에 미치는 영향 분석

**5) 신경형 데이터셋 확충**

- DVS(Dynamic Vision Sensor) 데이터셋 확대
- 일상적 시각 작업을 포함한 현실적 벤치마크 개발

**6) 하이브리드 접근법**

완전 SNN이 아닌, ANN과 SNN을 선택적으로 결합하는 혼합 모델의 개발로 정확도와 효율성의 균형을 맞춥니다.[3]

**7) 에너지 효율성 측정의 표준화**

SNN의 에너지 효율성을 공정하게 평가하기 위해 하드웨어 플랫폼 및 시뮬레이션 환경을 고려한 표준화된 메트릭이 필요합니다.[11]

### 결론

**Spiking Deep Residual Network** 논문은 SNN 분야에서 획기적인 기여를 했습니다. 특히 깊은 신경망 구축의 가능성을 입증하고, Residual 구조를 SNN에 효과적으로 통합하는 방법을 제시했습니다.[1]

논문이 제안한 **shortcut 정규화 모델**과 **전파 오류 보상 메커니즘**은 이후 SNN 변환 연구의 기초가 되었으며, 최근의 시간적 정규화, 수상돌기 뉴런 모델, 트랜스포머 기반 SNN 등의 발전으로 이어졌습니다.[4][5][6][7][2][3]

향후 연구의 성공 여부는 **이론적 개선**, **하드웨어 구현**, **대규모 데이터셋에서의 성능 검증**의 세 축에 달려 있습니다. 특히 신경형 칩의 상용화와 함께 실제 에너지 절감을 입증하는 것이 SNN의 광범위한 채택을 위한 핵심 과제입니다.

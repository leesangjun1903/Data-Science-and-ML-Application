# AutoSNN: Towards Energy-Efficient Spiking Neural Networks

### 1. 핵심 주장과 주요 기여

**AutoSNN**은 기존 스파이킹 신경망(SNNs)의 아키텍처 설계가 최적화되지 않았다는 문제 인식에서 출발합니다. 논문의 핵심 주장은 다음과 같습니다:[1]

- **기존 연구의 한계**: 이전 SNN 연구들은 훈련 방법 최적화에만 집중하였으며, 아키텍처의 영향을 거의 고려하지 않았습니다.[1]
  
- **주요 기여**: AutoSNN은 **스파이크 인식형 신경 아키텍처 탐색(Spike-aware NAS)** 프레임워크를 제안하여, 정확도와 에너지 효율성(생성 스파이크 수)을 동시에 고려한 SNN 아키텍처 자동 설계를 가능하게 했습니다.[1]

### 2. 해결 문제 및 제안 방법

#### 2.1 문제 정의

SNN이 신경형 칩(neuromorphic chips)에서 실행될 때, 막대한 스파이크는 코어 간 통신 오버헤드를 증가시켜 에너지 소비를 크게 악화시킵니다. 따라서 **정확도와 스파이크 수 두 가지 목표를 동시에 최적화**해야 합니다.[1]

#### 2.2 아키텍처 분석

AutoSNN은 먼저 기존 SNN의 아키텍처 선택들을 분석합니다:[1]

- **전역 평균 풀링(GAP) 계층의 문제점**: GAP 계층 사용 시 정확도가 86.93%에서 85.05%로 감소하며, 스파이크도 154K에서 168K로 증가합니다. 이는 GAP 계층이 정보 손실을 야기하기 때문입니다.[1]

- **다운샘플링 방식 분석**: 최대 풀링이 학습 가능한 스파이킹 블록이나 평균 풀링보다 에너지 효율적입니다. 학습 가능한 블록 사용 시 스파이크가 44% 증가합니다.[1]

#### 2.3 제안되는 방법론

**LIF(Leaky Integrate-and-Fire) 뉴런 모델**이 기본입니다:

$$V_{\text{mem}}^{l}(t) = \alpha_{\text{decay}} V_{\text{mem}}^{l}(t-1) + V_{\text{reset}} z^l(t) + z^l(t)$$

이를 이산 시간 형태로 표현하면:[1]

$$z^l(t) = w^l \cdot o^{l-1}(t) + b^l$$

$$H^l(t) = (1 - \alpha_{\text{decay}}) V^l_{\text{mem}}(t-1) + \alpha_{\text{decay}} z^l(t)$$

$$s^l(t) = \Theta(H^l(t) - V_{th})$$

$$V^l_{\text{mem}}(t) = H^l(t) - V_{\text{reset}} \cdot s^l(t)$$

여기서 $$V_{\text{mem}}$$은 막전위, $$V_{th}$$는 역치 전압, $$\Theta$$는 Heaviside 함수입니다.[1]

논문에서는 **PLIF(Parametric LIF)** 뉴런을 사용하며, $$1 - \alpha_{\text{decay}}$$를 시그모이드 함수 $$\frac{1}{1+\exp(-\beta)}$$로 대체하여 학습 가능하게 만듭니다.[1]

### 3. 모델 구조

#### 3.1 탐색 공간(Search Space) 설계

**두 단계의 탐색 공간**으로 구성됩니다:[1]

1. **매크로 레벨**: 기본 아키텍처 구조(SNN1)로 정해집니다
2. **마이크로 레벨**: 5가지 스파이킹 블록 후보:
   - Skip 연결
   - SCB (Spiking Convolution Block, 커널 크기 3×3)
   - SCB (커널 크기 5×5)
   - SRB (Spiking Residual Block, 커널 크기 3×3)
   - SRB (커널 크기 5×5)

전체 탐색 공간은 $$5^5 = 3,125$$개 아키텍처를 포함합니다.[1]

#### 3.2 스파이크 인식형 적응도 함수

AutoSNN의 핵심은 **스파이크를 명시적으로 고려하는 적응도 함수**입니다:[1]

$$F_A = \text{Accuracy} - \lambda \exp\left(\frac{N - N_{\text{avg}}}{N_{\text{avg}}}\right)$$

여기서:
- $$N$$: 아키텍처 A가 생성한 스파이크 수
- $$N_{\text{avg}}$$: 슈퍼네트워크 훈련 중 샘플링된 아키텍처들의 평균 스파이크 수
- $$\lambda > 0$$: 스파이크 인식 항의 영향을 제어하는 계수

$$\lambda$$를 증가시키면 더 적은 스파이크를 생성하는 아키텍처를 발견합니다.[1]

#### 3.3 아키텍처 탐색 알고리즘

**두 개의 연속 절차**로 구성됩니다:[1]

1. **슈퍼네트워크 훈련**: 
   - 단일 경로 균일 샘플링(single-path uniform sampling)을 사용
   - 훈련 데이터에서 추출한 미니배치마다 샘플링된 아키텍처 훈련
   - GPU 시간: ~6시간 48분

2. **진화 탐색**:
   - 상위-k 풀(Ptop)과 평가 풀(Peval) 유지
   - 변이(mutation)와 교차(crossover) 연산으로 아키텍처 생성
   - 200개 아키텍처 평가 예산 내에서 최고 적응도 아키텍처 선택
   - 추가 탐색 비용: ~8분

### 4. 성능 향상

#### 4.1 CIFAR-10에서의 결과

| 모델 | 정확도(%) | 스파이크 수 | 파라미터(M) |
|------|----------|----------|----------|
| CIFARNet-Wu | 90.53 | - | 45.05 |
| CIFARNet-Fang | 92.33 | 290K | 9.23 |
| ResNet11-Lee | 90.24 | 1530K | 18.30 |
| ResNet19-Zheng | 93.07 | 1246K | 14.69 |
| **AutoSNN** | **93.15** | **310K** | 20.92 |

AutoSNN은 손으로 설계된 SNNs보다 정확도는 비슷하거나 높으면서 **스파이크는 훨씬 적게 생성**합니다.[1]

#### 4.2 다양한 데이터셋에서의 일반화 성능

| 데이터셋 | 모델 | 정확도(%) | 스파이크 수 |
|---------|------|----------|----------|
| CIFAR-100 | Fang et al. | 66.83 | 716K |
| | AutoSNN | **69.16** | **326K** |
| SVHN | Fang et al. | 91.38 | 462K |
| | AutoSNN | **91.74** | **215K** |
| Tiny-ImageNet-200 | Fang et al. | 45.43 | 1724K |
| | AutoSNN | **46.79** | **680K** |
| CIFAR10-DVS | Zheng et al. | 66.10 | 1550K |
| | AutoSNN | **72.50** | **1269K** |

AutoSNN은 정적 데이터셋과 신경형 데이터셋 모두에서 일관되게 우수한 성능을 보입니다.[1]

### 5. 일반화 성능 향상

#### 5.1 탐색 알고리즘의 유효성

**절제 연구(Ablation Study)**를 통해 AutoSNN의 유효성을 검증합니다:[1]

- **무작위 샘플링**: 86.97 ± 1.06% 정확도, 123K ± 29K 스파이크
- **가중치 공유 + 무작위 탐색**: 88.40% 정확도, 132K 스파이크
- **가중치 공유 + 진화 탐색 (AutoSNN)**: **88.69%** 정확도, **127K** 스파이크

진화 탐색이 무작위 탐색보다 약 0.3% 정확도 향상과 5K 스파이크 감소를 달성합니다.[1]

#### 5.2 SNN 특성을 고려한 탐색의 중요성

**ANN 탐색 공간에서의 비교**:[1]

| 탐색 공간 | 정확도(%) | 스파이크 수 |
|---------|----------|----------|
| ANN 공간 (스파이킹 뉴런 제거) | 88.02 | 134K |
| **제안된 SNN 공간** | **88.69** | **127K** |

SNN 공간에서의 탐색이 **0.67% 더 높은 정확도**와 **7K 더 적은 스파이크**를 달성하며, 이는 SNN의 고유한 특성을 명시적으로 고려하는 것이 중요함을 보여줍니다.[1]

#### 5.3 확대된 탐색 공간에서의 성능

AutoSNN은 8개의 TBD 블록을 포함한 확대된 탐색 공간(390,625개 아키텍처)에서도 효과적입니다:[1]

- **확대 공간에서 AutoSNN (λ=0.08)**: 87.92% 정확도, 65K 스파이크
- **모든 블록을 SCB k3으로 채운 경우**: 87.04% 정확도, 230K 스파이크

### 6. 한계

#### 6.1 탐색 비용

- 슈퍼네트워크 훈련: ~6.8 GPU 시간
- 추가 탐색 비용: ~8분 (200개 아키텍처 평가)
- 상당한 초기 투자가 필요하지만, 훈련된 슈퍼네트워크는 재사용 가능[1]

#### 6.2 제한된 탐색 공간

- 정해진 매크로 아키텍처에 의존
- 보다 근본적인 아키텍처 수정은 어려움
- 고정된 스파이킹 블록 후보 집합[1]

#### 6.3 시간 단계와 스파이크 수의 트레이드오프

- $$\lambda$$ 값 조정으로 정확도와 에너지 효율성 간 트레이드오프 필요
- 최적 $$\lambda$$ 선택은 응용에 따라 달라짐[1]

#### 6.4 신경형 칩 의존성

- 실제 신경형 칩에서의 성능 검증이 시뮬레이션에만 국한
- 실제 하드웨어 배포에서의 효과는 추가 검증 필요[1]

### 7. 앞으로의 연구 방향 및 시사점

#### 7.1 일반화 성능 개선

최근 연구들이 SNN의 일반화 성능 향상에 주력하고 있습니다:[2][3][4][5]

- **시간적 역전 정규화(TRR)**: 입력/특성의 시간적 역전 섭동을 활용하여 과적합을 완화하고 일반화를 개선합니다. 신경형 데이터셋에서 저지연 SNN의 인식 정확도를 크게 향상시킵니다.[5]

- **다중 스케일 융합 강화 SNN(MFSNN)**: 뇌컴퓨터 인터페이스(BCI) 응용에서 시간적 합성곱 신경망과 채널 주의 메커니즘을 활용하여 실시간 효율적 신호 해석을 달성합니다.[3]

- **활동 기반 학습**: 생물학적 증거 기반 학습 메커니즘(PSAC)이 MNIST에서 97.7%, CIFAR-10에서 93.73% 정확도를 달성합니다.[6]

#### 7.2 하드웨어-소프트웨어 공동 최적화

- **신경형 칩 기반 구현**: Loihi와 같은 신경형 칩에 직접 SNN 매핑[7][1]
- **메모리 내 컴퓨팅**: 메모리와 계산의 분리를 극복하기 위한 in-memory computing 기술[7]
- **양자화 및 프루닝**: 에지 디바이스 배포를 위한 모델 압축 기술[8]

#### 7.3 확장성 연구

**대규모 SNN 개발**이 중요한 과제입니다:[9]

- **스파이킹 트랜스포머**: 주의 메커니즘과 결합한 SNN 구조
- **언어 모델링**: SpikeLM으로 언어 작업에 SNN 적용[10]
- **비전 작업 확장**: 객체 감지, 추적 등으로 응용 범위 확대[11]

#### 7.4 신경형 컴퓨팅의 미래

최신 신경형 컴퓨팅 연구는 다음 방향으로 진행 중입니다:[12][7]

- **신경형 장치 개발**: 바이오인스파이어드 나노 스케일 디바이스
- **이벤트 기반 처리**: 비동기 스파이크 기반 계산으로 실제 신경 시스템에 더 가까운 구현[13]
- **응용 다양화**: 의료 진단, 자율 주행, 로봇공학, 엣지 컴퓨팅[14]

#### 7.5 AutoSNN 이후의 고려사항

1. **더 정교한 적응도 함수 설계**: 에너지, 지연시간, 정확도의 다중 목표 최적화

2. **동적 아키텍처 탐색**: 서로 다른 신경형 칩 특성에 맞춘 자동 적응

3. **전이 학습**: 한 데이터셋에서 탐색한 아키텍처의 다른 도메인 적용성 향상

4. **실시간 컴파일러**: 탐색된 아키텍처의 신경형 하드웨어에 효율적 매핑

5. **시간 단계 동적 조정**: 입력 복잡도에 따른 적응적 시간 단계 관리

### 결론

**AutoSNN**은 SNN 설계에 신경 아키텍처 탐색을 처음으로 체계적으로 적용하여, 정확도와 에너지 효율성 간 파레토 최적 아키텍처를 발견합니다. 다양한 데이터셋에서 손으로 설계된 SNN을 능가하는 성능을 입증하며, **스파이크 인식형 적응도 함수**를 통해 두 가지 상충되는 목표를 효과적으로 균형 있게 최적화합니다.[1]

향후 연구는 더 큰 아키텍처 공간, 실제 신경형 하드웨어 배포, 그리고 다양한 도메인 확장으로 나아갈 것으로 예상되며, SNN의 일반화 성능 개선과 신경형 컴퓨팅 패러다임의 실현이 핵심 과제입니다.[2][3][5][9][12][7]

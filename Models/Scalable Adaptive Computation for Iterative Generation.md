# Scalable Adaptive Computation for Iterative Generation

### 1. 논문의 핵심 주장 및 주요 기여

**Recurrent Interface Networks (RINs)**은 자연 데이터의 비균등한 정보 분포를 효율적으로 처리하기 위해 설계된 주의 기반 아키텍처입니다. 논문의 핵심 주장은 기존 CNN과 Transformer와 같은 주류 아키텍처들이 입력 데이터 공간 전체에 걸쳐 균일하게 계산을 배치하는 것이 비효율적이라는 점입니다.[1]

**주요 기여는 다음과 같습니다**:[1]

- 데이터 차원에서 핵심 계산을 분리하는 도메인 불변 아키텍처 제안
- 반복 계산 설정에서 활용할 수 있는 **잠재 자기조건화(Latent Self-Conditioning)** 메커니즘 도입
- 기존 U-Net 확산 모델 대비 최대 10배 효율성 향상을 달성하면서도 우수한 성능 달성
- 캐스케이드나 가이던스 없이 1024×1024 고해상도 이미지 생성 가능

***

### 2. 해결하고자 하는 문제

**문제 정의**:[1]
고차원 데이터(이미지, 비디오) 생성 시 기존 아키텍처의 한계는 다음과 같습니다:

1. **입력 크기에 비례하는 계산 비용**: CNN과 Transformer 모두 입력 크기에 따라 계산이 선형 또는 이차적으로 증가합니다[1]
2. **비적응적 계산 할당**: 배경이 단순한 영역과 복잡한 텍스처의 영역에 동일한 계산을 할당합니다[1]
3. **메모리 병목**: 고해상도 이미지 처리 시 메모리 사용이 급증합니다[1]

예를 들어, 단순한 하늘 배경을 가진 이미지 생성에서는 복잡한 객체 영역에만 집중된 계산이 이상적이지만, 기존 아키텍처는 모든 픽셀에 동등한 처리를 합니다.[1]

### 3. 제안하는 방법론 (수식 포함)

#### 3.1 기본 확산 모델 배경[1]

확산 모델은 데이터 분포에서 노이즈로의 전방 과정을 정의합니다:

$$ x_t = \sqrt{\gamma(t)} x_0 + \sqrt{1 - \gamma(t)} \epsilon $$

여기서 $$\epsilon \sim \mathcal{N}(0, I)$$, $$t \sim \mathcal{U}(0,1)$$, $$\gamma(t)$$는 단조 감소 함수입니다.[1]

역방향 과정에서 신경망 $$f(x_t, t)$$는 노이즈를 예측합니다:

$$ \mathcal{L} = \mathbb{E}_{t \sim \mathcal{U}(0,1), \epsilon \sim \mathcal{N}(0,1)} \|f(\sqrt{\gamma(t)} x_0 + \sqrt{1 - \gamma(t)} \epsilon, t) - \epsilon\|^2 $$

#### 3.2 RIN 블록 구조[1]

RIN의 핵심은 인터페이스 $$X \in \mathbb{R}^{n \times d}$$와 잠재 $$Z \in \mathbb{R}^{m \times d'}$$ 간의 정보 라우팅입니다. 여기서 $$|Z| \ll |X|$$입니다[1].

**Read 연산** (인터페이스에서 잠재로 정보 로드):

$$ Z = Z + \text{MHA}(Z, X) $$

$$ Z = Z + \text{MLP}(Z) $$

**Compute 연산** (잠재 간 정보 교환, K 레이어 반복):

$$ Z = Z + \text{MHA}(Z, Z) \quad (\times K) $$

$$ Z = Z + \text{MLP}(Z) $$

**Write 연산** (잠재에서 인터페이스로 업데이트 쓰기):

$$ X = X + \text{MHA}(X, Z) $$

$$ X = X + \text{MLP}(X) $$

여기서 MHA는 다중 헤드 주의이고, MLP는 다층 퍼셉트론입니다. 주의 메커니즘은 다음과 같이 정의됩니다:[1]

$$ \text{Attention}(Q, K, V) = \text{softmax}\left(\frac{QK^T}{\sqrt{d_k}}\right)V $$

#### 3.3 잠재 자기조건화(Latent Self-Conditioning)[1]

RIN의 핵심 혁신은 이전 반복의 잠재를 현재 반복의 초기화에 사용하는 것입니다:

$$ Z_t = Z_{\text{init}} + \text{LayerNorm}(Z_{t'} + \text{MLP}(Z_{t'})) $$

여기서 $$Z_{t'}$$는 이전 시간 단계의 잠재입니다.[1]

**훈련 시 절차**:
- 확률 $$p_{\text{cond}}$$로 먼저 $$f(x_t, t, 0)$$을 실행하여 잠재 추정:

$$\tilde{Z}_t = f(x_t, t, 0) $$[1]

- 그런 다음 중단된 기울기(stop-gradient)를 적용하여 조건화:

```math
\epsilon_{\text{pred}} = f(x_t, t, \text{stop\_gradient}(\tilde{Z}_t))
```

손실 계산:

$$\mathcal{L} = \|\epsilon_{\text{pred}} - \epsilon\|^2 $$

**샘플링 시 절차**:
반복적으로 이전 단계의 잠재를 사용:

$$ \epsilon_{\text{pred}}, Z_t = \text{RIN}((x_t, Z_{t-\Delta}), t) $$

이 방식은 역전파 시간(Backpropagation Through Time, BPTT)을 필요로 하지 않으면서도 반복 네트워크의 이점을 제공합니다.[1]

### 4. 모델 구조

#### 4.1 전체 아키텍처[1]

RIN은 다음과 같은 계층적 구조를 갖습니다:

```
입력 (이미지/비디오)
    ↓
토큰화 (패치 임베딩)
    ↓
인터페이스 초기화: X ∈ ℝ^{n×d}
잠재 초기화: Z_init ∈ ℝ^{m×d'}
    ↓
RIN 블록 × L개:
  - Read: 크로스 주의로 X → Z
  - Compute: 자기 주의로 Z 처리 (× K개)
  - Write: 크로스 주의로 Z → X
    ↓
선형 판독출: X → 예측
    ↓
패치 재구성 → 최종 출력
```

#### 4.2 구성 설정[1]

| 해상도 | 잠재 개수 | 잠재 차원 | 인터페이스 토큰 | 인터페이스 차원 | 블록 수 | 깊이 K |
|--------|----------|----------|---------------|----------------|--------|--------|
| 64×64 | 128 | 1024 | 256 | 512 | 4 | 4 |
| 256×256 | 256 | 1024 | 1024 | 512 | 6 | 4 |
| 512×512 | 256 | 768 | 4096 | 512 | 6 | 6 |
| 1024×1024 | 256 | 768 | 16384 | 512 | 6 | 8 |

핵심 관찰: 16384개의 인터페이스 토큰(1024×1024 이미지)에도 불구하고 256개의 잠재만으로 충분합니다.[1]

#### 4.3 노이즈 스케줄[1]

코사인 스케줄에서 발생하는 불안정성을 해결하기 위해 시그모이드 기반 스케줄 도입:

$$ \gamma_{\text{sigmoid}}(t) = \frac{-\sigma\left(\frac{t(e-s) + s}{\tau}\right) + v_e}{v_e - v_s} $$

여기서 $$s=-3$$, $$e=3$$, $$\tau$$는 온도 매개변수(기본값 0.9)입니다.[1]

|---------|-------|------|-------|-------|---------|
| ImageNet | 64×64 | RIN | 1.23 | 66.5 | 106 |
| | | ADM | 2.07 | 63.4 | 210 |
| | 128×128 | RIN | 2.75 | 144.1 | 194 |
| | | CDM | 3.51 | 128.0 | 1268 |
| | 256×256 | RIN | 4.51 | 161.0 | 334 |

| | 512×512 | RIN+scale | 3.95 | 216.0 | 415 |
| | | ADM+guide | 7.72 | 172.7 | >4122 |

주요 성과:[1]
- **FID 개선**: 256×256에서 ADM+가이던스 대비 약간 우수
- **효율성**: 256×256에서 334 GFLOPs (CDM의 2620 vs, 약 7.8배 감소)
- **단순성**: 가이던스나 캐스케이드 없이 고해상도 이미지 생성

#### 5.2 비디오 예측 성능[1]

Kinetics-600 데이터셋 (16×64×64 해상도):

| 모델 | FVD ↓ | IS ↑ | GFLOPs |
|------|-------|------|---------|
| RIN (400 steps) | 11.5 | 17.7 | 386 |
| RIN (1000 steps) | 10.8 | 17.7 | 386 |
| Video Diffusion† | 16.6 | 15.64 | 4136 |
| Transframer | 25.4 | - | - |

**효율성**: 비디오 확산 모델 대비 10.7배 FLOP 감소[1]

#### 5.3 잠재 자기조건화의 효과[1]

자기조건화 비율에 따른 FID 변화:
- 비율 0.0 (자기조건화 없음): FID ~6.0-7.0
- 비율 0.5: FID ~4.5-5.0
- 비율 0.9 (최적): FID ~4.3-4.5

**결론**: 자기조건화가 매우 중요하며, 이는 더 나은 라우팅을 위한 문맥 제공을 가능하게 합니다.[1]

### 6. 모델의 일반화 성능 향상 가능성

#### 6.1 현재 강점[1]

1. **도메인 불변성**: 패치 임베딩 이외에는 도메인별 귀납적 편향이 없어, 다양한 모달리티(이미지, 비디오, 심지어 3D 데이터)에 적용 가능[1]

2. **적응적 계산**: 읽기 주의 맵 시각화 결과, 모델이 생성 과정의 각 단계에서 동적으로 정보 라우팅을 학습합니다. 초기 반복에서는 광범위하게 정보를 수집하고, 후기 반복에서는 고정보 영역(복잡한 객체, 움직이는 영역)에 집중[1]

3. **작은 데이터셋에서의 성능**: CIFAR-10에서 1.81 FID (최첨단 EDM: 1.79 FID)를 달성하면서 EDM 대비 2배 작은 모델(31M vs ~100M)과 10배 빠른 훈련[1]

#### 6.2 일반화 성능 향상의 증거[1]

**1. 계층적 피처 학습**:
- 읽기 주의 시각화(Figure 6)가 계층을 거치며 점진적으로 정보 라우팅이 세밀해지는 것을 보여줍니다[1]
- 블록 1-3: 광범위한 정보 수집
- 블록 4-6: 고정보 영역에 집중된 계산

**2. 비디오에서의 시간적 적응**:
- 비디오 생성에서 모델이 고정된 배경에서는 정보를 복사하고, 움직이는 영역(객체 모션, 카메라 팬)에 집중된 계산을 할당[1]
- 이는 시간적 중복성을 효율적으로 활용함을 시사합니다

**3. 아블레이션 연구**:[1]
- 블록 스택의 중요성: 다중 읽기-쓰기 순환이 더 나은 일반화를 가능하게 합니다
- 단일 읽기-쓰기 (PerceiverIO 유사): 더 빨리 포화 (성능 한계)
- 다중 순환: 성능 포화가 늦게 나타나고 더 높은 최종 성능 달성

**4. 토큰화 유연성**:[1]
- 4×4 패치에서 1×1 패치(4096개 토큰)까지 다양한 토큰화 방식을 처리할 수 있어, 다양한 입력 분포에 대한 강건성을 시사합니다

#### 6.3 향후 일반화 성능 향상 방향[1]

1. **도메인 간 전이 학습**: 이미지 생성 모델을 비디오나 3D에 직접 적응시킬 가능성 높음

2. **조건부 생성 확장**: 클래스 조건화 외에도 다양한 형태의 조건화(텍스트, 마스크, 스케치)에 자연스럽게 확장 가능

3. **하이브리드 접근**: 가이던스와의 결합으로 추가 성능 향상 가능 (현재 미사용)

### 7. 한계 및 제약사항

#### 7.1 논문에서 확인된 한계[1]

1. **라우팅의 복잡성**: 인터페이스와 잠재 간 정보 교환이 개선되지 않으면, 얕은 라우팅과 성능 저하 초래 가능[1]

2. **초기화 비용**: 잠재 자기조건화 없이는 각 전방 패스마다 "콜드 스타트" 문제 발생[1]

3. **하이퍼파라미터 민감성**:[1]
   - 노이즈 스케줄: 고해상도에서 코사인 스케줄이 불안정
   - 자기조건화 비율: 최적값(0.9) 근처에서만 최고 성능

4. **메모리 오버헤드**: 잠재 자기조건화를 위해 추가 메모리 필요 (훈련 중 <25% 증가, 샘플링 중 무시할 수 있음)[1]

#### 7.2 구조적 한계

1. **토큰 수 의존성**: 16384개 토큰(1024×1024)도 처리하지만, 3D 데이터나 시계열처럼 더 높은 차원에서는 토큰 수가 급증할 수 있습니다

2. **주의 메커니즘의 이차성**: 잠재 자체 주의는 여전히 $$\mathcal{O}(m^2)$$의 복잡도를 가지며, $$m$$이 커지면 병목이 될 수 있습니다

3. **도메인별 최적화의 필요성**: 현재 구현은 "도메인 불변"이지만, 특정 도메인에 최적화된 버전이 더 나은 성능을 제공할 가능성

### 8. 논문이 앞으로의 연구에 미치는 영향

#### 8.1 확산 모델 아키텍처의 진화[1]

이 논문은 다음과 같은 중요한 패러다임 전환을 제시합니다:

1. **CNN/U-Net 중심에서의 탈피**: 기존 확산 모델의 표준 아키텍처인 U-Net을 대체할 수 있는 효율적인 대안 제시. 동시대 연구(2023년경 DiT, Peebles & Xie, 2022)와 유사한 방향성을 보이면서도 더 높은 효율성 달성[1]

2. **적응 계산의 실용화**: 이론적으로만 논의되던 적응 계산을 실제 고차원 생성 작업에서 효과적으로 구현[1]

3. **반복 계산의 중요성**: 확산 모델의 점진적 정제 특성을 아키텍처 수준에서 활용하는 새로운 관점 제시[1]

#### 8.2 관련 최신 연구 추세 (2023-2025)[2][3][4][5][6]

**1. Diffusion Transformer (DiT) 계열**:
- 논문 발표 후 변환기 기반 확산 모델이 주류화됨[4][7][2]
- RIN의 선택적 주의 메커니즘 개념이 효율적 변환기 설계의 영감 제공

**2. 효율적 아키텍처 개선**:
- EfficientFormer: 모바일 배포를 위한 저지연 변환기[8]
- AdaViT: 적응형 토큰으로 계산 비용 동적 조정[9]
- RIN과 유사한 적응 계산 개념 확대[10]

**3. 비디오 생성 확장**:
- SimDA: T2I 모델을 비디오로 효율적 적응[11]
- VidHRFormer: 공간-시간 주의 분리를 통한 효율성 향상[12]
- RIN의 반복 계산 개념이 비디오 특화 모델로 발전

**4. 잠재 공간 기반 확산**:
- Latent Diffusion Models이 주류화되면서 RIN 같은 효율적 아키텍처 수요 증가[13][4]
- 픽셀 공간 확산의 한계를 보여주면서도 고효율을 달성한 RIN이 중요한 참조점

**5. 조건부 확산 모델**:
- eDiff-I: 생성 단계별 특화된 모델 앙상블[14]
- ProSpect: 단계별 주파수 표현 제어[15]
- RIN의 단계별 적응 계산이 이러한 단계 특화 접근의 선구자

#### 8.3 구체적 연구 방향 제시

**1. 멀티모달 생성으로의 확장**:
- 도메인 불변 설계로 인해 텍스트, 오디오, 3D 등으로 자연스러운 확장 가능[1]
- 현재는 이미지/비디오에만 적용되었으나, 일반적 구조는 모든 시퀀셜 생성 작업 지원

**2. 자기감시 학습(Self-Supervised Learning) 통합**:
- 잠재 자기조건화 개념이 자기감시 학습의 새로운 형태로 발전 가능
- 네트워크의 숨겨진 표현을 조건으로 사용하는 메커니즘의 일반화

**3. 소수샷(Few-Shot) 및 영상샷(Zero-Shot) 학습**:
- 적응 계산의 유연성이 제한된 데이터 환경에서 강력한 성능 제공 가능성[1]
- CIFAR-10 예제에서 작은 모델로도 SOTA 달성한 증거

**4. 하드웨어 최적화**:
- 현재 구현이 "하드웨어 친화적" 고정 계산 그래프를 유지하면서도 효율성 달성[1]
- 향후 동적 계산 그래프를 지원하는 특화 하드웨어 개발 시 추가 성능 향상 예상

***

### 9. 앞으로 연구 시 고려할 점

#### 9.1 아키텍처 개선[1]

1. **더 효율적인 라우팅 메커니즘**:
   - 현재 크로스 주의 기반 라우팅 외 스파스 라우팅, 소프트-탑-K 라우팅 등 탐색
   - 병렬화 가능한 새로운 라우팅 패턴 개발

2. **계층별 잠재 크기 동적 조정**:
   - 현재 모든 블록에서 고정된 잠재 수 사용
   - 초기 블록에서는 더 많은 잠재, 후기 블록에서는 더 적은 잠재 활용 고려

3. **혼합 정밀도 훈련**:
   - 충분히 견고한 아키텍처이므로 FP16/BF16 혼합 정밀도 실험 가능

#### 9.2 훈련 최적화[1]

1. **더 나은 노이즈 스케줄 탐색**:
   - 시그모이드 스케줄이 개선을 보이지만, 고해상도 안정성을 위한 추가 개선 필요[1]
   - 주파수 기반 스케줄 등 새로운 접근 탐색

2. **자기조건화 비율의 동적 조정**:
   - 현재 고정된 0.9 비율 사용
   - 훈련 진행도에 따라 비율 증가 (따뜻한 시작) 고려

3. **잠재 초기화 전략**:
   - 현재 학습 가능한 임베딩으로 초기화
   - 입력 의존적 초기화나 하이브리드 초기화 탐색

#### 9.3 평가 메트릭 개선[1]

1. **계산 효율성의 더 정확한 측정**:
   - 현재 GFLOPs만 고려하나, 실제 벽 시간(wall-clock time)과의 관계 분석 필요
   - 메모리 대역폭, 캐시 효율성 등 하드웨어 특성 고려

2. **적응 계산의 정량화**:
   - 실제로 할당된 계산이 데이터 복잡도와 얼마나 잘 상관되는지 측정
   - 엔트로피 기반 메트릭으로 라우팅 스파시티 평가

#### 9.4 응용 분야 확대[1]

1. **조건부 생성의 정교화**:
   - 텍스트-이미지 생성으로의 확장 (현재는 클래스 조건화만 사용)
   - 구조화된 조건(마스크, 스케치, 레이아웃) 처리

2. **시계열 및 신호 처리**:
   - 오디오, 센서 데이터 등 1D 신호 생성에의 적용
   - 시간-채널 토큰화 전략 설계

3. **3D 생성의 효율화**:
   - 복셀, 메시, NeRF 등 3D 표현에 대한 RIN 적용
   - 3D 특화된 라우팅 전략 개발

#### 9.5 이론적 이해 심화

1. **라우팅 학습의 이론적 분석**:
   - 왜 단순한 크로스 주의가 효과적인 라우팅을 학습하는가?
   - 수렴성, 최적성 보장 분석

2. **일반화 경계(Generalization Bounds)**:
   - RIN의 매개변수 수와 일반화 성능 간의 관계 수학적 분석
   - 적응 계산이 과적합을 얼마나 방지하는가?

3. **생물학적 영감**:
   - 인간 시각 시스템의 주의 메커니즘과의 유사성 탐구
   - 신경 가소성(neural plasticity)과의 개념적 연결

#### 9.6 하이브리드 접근

1. **RIN과 U-Net의 하이브리드**:
   - U-Net의 인덕티브 바이어스와 RIN의 적응성 결합
   - 예: 낮은 해상도에서 U-Net, 높은 해상도에서 RIN

2. **RIN과 Latent Diffusion 결합**:
   - 압축된 레이턴트 공간에서 RIN 실행[1]
   - 픽셀 공간의 계산 비용과 레이턴트 공간의 해석 용이성 장점 결합

3. **앙상블 방법**:
   - 다양한 크기의 RIN 모델 앙상블
   - 계산-품질 트레이드오프 자동 최적화

### 10. 종합 평가

**강점**:
1. **혁신적 아키텍처**: 데이터 크기와 계산을 명시적으로 분리한 첫 번째 실용적 구현[1]
2. **우수한 효율성**: 10배 FLOPs 감소를 달성하면서도 성능 유지[1]
3. **도메인 불변성**: 이미지, 비디오에 동일 구조 적용 가능[1]
4. **명확한 해석가능성**: 읽기 주의 시각화로 모델의 적응 계산을 명확히 이해 가능[1]

**약점**:
1. **반복 계산에 특화**: 일반적 태스크가 아닌 반복 계산(확산) 설정에 최적화[1]
2. **라우팅 메커니즘의 복잡성**: 잠재와 인터페이스 간 정보 교환이 효과적으로 학습되지 않으면 문제[1]
3. **현재 피크스: 고해상도에서만 이점**: 저해상도에서는 U-Net과의 차이 미미[1]

**미래 전망**:
이 논문은 확산 모델 기반 생성 AI의 효율성 향상에 새로운 방향을 제시했습니다. 특히 **적응 계산**이라는 오래된 개념을 반복 생성 작업에 성공적으로 구현함으로써, 향후 연구자들에게 구체적인 설계 원칙을 제공합니다. 2023년 이후 DiT, 효율적 Transformers 등의 발전이 이 논문의 영향을 반영하고 있으며, 멀티모달 생성, 자기감시 학습, 하드웨어 특화 최적화 등 다양한 방향으로의 확장 가능성이 매우 높습니다.[3][2][4][1]

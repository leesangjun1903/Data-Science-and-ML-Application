## 1. 핵심 주장과 주요 기여 요약

클래스 불균형(Class Imbalance)은 다양한 실세계 응용 분야에서 빈번하게 나타나며, 딥러닝을 포함한 모델 학습에 심각한 도전 과제를 제기한다.

이 논문의 핵심 주장은 다음과 같습니다:

딥 컨볼루션 신경망(CNN)에 앙상블 학습을 통합하여 클래스 불균형 학습 문제를 해결하며, CNN의 다양한 은닉층에서 분기하는 보조 분류기(auxiliary classifiers)들의 앙상블이 CNN과 함께 종단간(end-to-end) 방식으로 학습된다.

**주요 기여:**
1. 다수 클래스에 대한 편향을 교정할 수 있는 새로운 손실 함수를 설계하였으며, 이 함수는 CNN의 은닉층과 보조 분류기들이 이전 레이어에서 오분류된 샘플에 집중하도록 강제함으로써 후속 레이어들이 다양한 행동을 발전시키고 배치 단위 방식으로 이전 레이어의 오류를 수정할 수 있도록 한다.

2. 보조 분류기들의 앙상블은 주 CNN과 함께 더 강력한 결합 분류기를 형성하거나, CNN 학습이 완료된 후 제거하여 CNN의 클래스 불균형 학습을 보조하는 역할만 수행함으로써 불균형 데이터 처리 능력을 향상시킬 수 있다는 독특한 특성을 가진다.

3. CIFAR-10, CIFAR-100, iNaturalist, CelebA의 4가지 벤치마크 데이터셋에 대한 포괄적 실험이 수행되었으며, 최신 딥 불균형 학습 방법들 대비 유의미한 성능 향상을 입증하였다.

## 2. 해결하고자 하는 문제, 제안 방법, 모델 구조, 성능 및 한계

### 2-1. 해결하고자 하는 문제

클래스 불균형은 다양한 실세계 응용 분야에서 널리 나타나며 딥러닝을 포함한 모델 학습에 상당한 어려움을 제기한다. 표준 CNN은 다수 클래스(majority class)에 편향되어 소수 클래스(minority class)를 제대로 학습하지 못하는 문제가 있습니다.

동일한 모델 아키텍처가 불균형 데이터로 학습될 때, 소수 클래스는 다수 클래스에 비해 일반화에 훨씬 더 큰 어려움을 보인다. 데이터가 불균형할 경우, 모델은 훈련 데이터를 거의 완벽하게 암기하지만 소수 클래스의 테스트 분포로의 일반화에 어려움을 겪는다.

### 2-2. 제안하는 방법 (수식 포함)

#### (1) 전체 구조 개요

백본 네트워크는 충분한 깊이를 가진 표준 CNN이면 무엇이든 사용 가능하며, 여러 서브 브랜치가 백본의 서로 다른 레이어에 부착된다. 학습 단계에서 특정 보조 분류기의 손실은 이전 분류기들이 제공한 사후 확률(posterior probability)을 기반으로 계산된다.

#### (2) 부스팅 기반 손실 함수 설계

이 논문의 핵심은 **배치 단위 부스팅(batch-wise boosting)** 전략을 CNN 내부에 내재화한 새로운 손실 함수입니다.

**① 기본 분류기 사후 확률 (첫 번째 보조 분류기):**

$$P_1(y \mid x) = \text{softmax}(f_1(x))$$

여기서 $f_1(x)$는 첫 번째 보조 분류기의 출력 로짓(logit)입니다.

**② $k$번째 보조 분류기의 가중 사후 확률:**

이전 분류기들이 오분류한 샘플에 더 높은 가중치를 부여합니다:

$$\tilde{P}_k(y \mid x) \propto \frac{P_k(y \mid x)}{P_{1:k-1}(y \mid x)}$$

즉, $k$번째 분류기의 유효 확률은 이전 $k-1$개 분류기들의 누적 예측에 반비례하여 가중됩니다.

**③ 앙상블 손실 함수:**

새로운 손실 함수는 다수 클래스에 대한 편향을 교정하기 위해, CNN의 은닉층과 보조 분류기들이 이전 레이어에서 오분류된 샘플에 집중하도록 강제한다.

전체 손실은 다음과 같이 구성됩니다:

$$\mathcal{L}_{\text{total}} = \mathcal{L}_{\text{main}} + \sum_{k=1}^{K} \lambda_k \cdot \mathcal{L}_k$$

- $\mathcal{L}_{\text{main}}$: 주 CNN의 크로스엔트로피 손실
- $\mathcal{L}_k$: $k$번째 보조 분류기의 가중 손실
- $\lambda_k$: 각 보조 분류기의 가중치 계수
- $K$: 보조 분류기 수

**④ 가중 크로스엔트로피 손실 (각 보조 분류기):**

$$\mathcal{L}_k = -\sum_{i} w_k(x_i) \log P_k(y_i \mid x_i)$$

여기서 샘플별 가중치 $w_k(x_i)$는 이전 분류기들의 오분류 정도에 비례하여 설정됩니다:

$$w_k(x_i) = \frac{1 - P_{1:k-1}(y_i \mid x_i)}{Z_k}$$

- $P_{1:k-1}(y_i \mid x_i)$: 이전 $k-1$개 분류기들의 누적 정분류 확률
- $Z_k$: 정규화 상수

이는 **AdaBoost**의 핵심 아이디어를 CNN 내부 레이어 간에 적용한 것입니다.

### 2-3. 모델 구조

백본 네트워크는 충분한 깊이를 가진 표준 CNN이면 무엇이든 사용 가능하며, 여러 서브 브랜치가 백본의 서로 다른 레이어에 부착된다.

얕은(shallow) 분류기는 더 거친(coarser) 특징을 기반으로 구축되고, 깊은(deeper) 분류기는 세밀한(fine-grain) 특징을 학습한다. 이러한 구조에서 계층적 특징이 서로 다른 분류기에 의해 포착될 수 있다.

학습 단계에서 특정 보조 분류기의 손실은 이전 분류기들이 제공한 사후 확률을 기반으로 계산된다. 제안 방법의 이점은 세 가지 측면에서 도출될 수 있다: (1) 비용 효율적인 방식의 딥 앙상블 구성, (2) 네트워크 정규화, (3) 기울기 소실 처리.

**구조 요약:**

```
입력 이미지
    │
    ▼
[Backbone CNN Layer 1~L]
    ├──── Branch 1 (보조 분류기 1: 얕은 특징 기반)
    ├──── Branch 2 (보조 분류기 2: 중간 특징 기반)
    ├──── Branch 3 (보조 분류기 3: 깊은 특징 기반)
    └──── Main Classifier (주 분류기)
              │
              ▼
      앙상블 결합 출력 또는 주 분류기 단독 출력
```

### 2-4. 성능 향상

CIFAR-10, CIFAR-100, iNaturalist, CelebA의 4개 벤치마크 데이터셋에서 포괄적인 실험이 수행되었으며, 최신 딥 불균형 학습 방법들 대비 유의미한 성능 향상이 입증되었다.

학습 시간은 동일한 서버에서 4개의 Titan-XP GPU로 측정되었으며, 언더샘플링 방법(ROS, ROS+)은 가장 적은 GPU 학습 시간을 요구하지만 가장 낮은 성능을 제공하는 것으로 나타났다.

### 2-5. 한계점

논문에서 직·간접적으로 확인된 한계는 다음과 같습니다:

1. **계산 비용 증가:** 보조 분류기 수($K$)에 비례하여 학습 파라미터와 순전파/역전파 연산량이 증가합니다.
2. **CNN 아키텍처 의존성:** 백본 네트워크는 충분한 깊이를 가진 표준 CNN이어야 하므로, 매우 얕은 네트워크에는 적용이 제한될 수 있습니다.
3. **보조 분류기 배치 위치 설계:** 어떤 레이어에 보조 분류기를 부착할지에 대한 최적화가 추가 하이퍼파라미터를 도입합니다.

## 3. 모델의 일반화 성능 향상 가능성

이 논문이 일반화 성능 향상에 기여하는 메커니즘은 크게 세 가지입니다.

### 3-1. 과적합 저항성 (Anti-Overfitting)

제안 방법은 더 나은 성능을 보여줄 뿐만 아니라, 학습 30 에폭 이후 일관되게 낮은 훈련 정확도를 제공함으로써 과적합에 대한 더 나은 저항성을 나타낸다. 유사한 정규화 효과가 GoogLeNet에서도 관찰되었는데, GoogLeNet 역시 아키텍처에 보조 분류기를 포함하고 있다.

### 3-2. 부스팅 전략의 일반화 기여

부스팅 방식의 전략은 균형 잡힌 데이터에서 더 나은 일반화로 이어질 수 있다.

### 3-3. 기울기 소실 문제 완화

기울기의 크기를 증폭함으로써, 제안 방법은 기울기 소실 문제를 처리할 더 나은 기회를 갖는다. 이는 소수 클래스 샘플에 대한 기울기 신호가 더 안정적으로 전파되도록 하여, 일반화 성능을 높이는 데 기여합니다.

### 3-4. 다양성(Diversity) 확보

다양성은 모든 앙상블이 작동하기 위한 필요 조건이다. 제안 방법으로 구성된 기본 분류기들이 다양한 행동을 보이는지 검증하기 위해, 다양한 불균형 비율을 가진 long-tailed 불균형 CIFAR-100에서 앙상블의 다양성을 보고하였다.

### 3-5. 소수 클래스에 대한 과적합 억제

불균형 데이터에서 모델은 훈련 데이터를 거의 완벽하게 암기하지만 소수 클래스의 테스트 분포로의 일반화에는 어려움을 겪는다. 이 논문의 배치 단위 부스팅 손실 함수는 이러한 문제를 직접적으로 완화합니다.

### 3-6. 경량화된 추론 가능성

리소스가 제한된 응용 분야에 매우 매력적일 수 있으며, 새로운 방법을 통해 더 적은 파라미터를 가진 네트워크(더 작은 네트워크)가 더 나은 불균형 학습 능력을 갖출 수 있다.

## 4. 앞으로의 연구에 미치는 영향과 고려할 점

### 4-1. 연구 영향

#### (가) 앙상블-딥러닝 통합 패러다임 확산

이 논문은 별도의 앙상블 모델 훈련 없이, **하나의 CNN 학습 과정 안에서** 앙상블 효과를 얻는 새로운 패러다임을 제시하였습니다. 앙상블 학습은 적응성, 견고성, 일반화 및 단일 분류기 대비 우수한 성능으로 인해 클래스 불균형 문제를 해결하기 위해 광범위하게 사용된다.

#### (나) Long-Tail 학습 연구의 발전

최근의 long-tailed 학습 연구들은 클래스 재균형(class re-balancing), 정보 증강(information augmentation), 모듈 개선(module improvement)의 세 가지 주요 범주로 그룹화될 수 있다. 이 논문은 이 세 가지 방향 모두에 기여했습니다.

#### (다) 2020년 이후 관련 최신 연구 비교 분석

| 연구 | 주요 방법 | 특징 |
|---|---|---|
| **본 논문 (Chen et al., 2021)** | CNN 내 앙상블 보조 분류기 + 부스팅 손실 | End-to-end, 제거 가능한 보조 분류기 |
| **LDAM-DRW (Cao et al., 2019)** | 레이블 분포 인식 마진 손실 | 마진 기반 결정 경계 조정 |
| **Decoupled Training (Kang et al., 2020)** | 표현 학습과 분류기 최적화 분리 | 2단계 학습 프레임워크 |
| **Open-Sampling (2022)** | OOD 데이터를 이용한 소수 클래스 재균형 | 외부 데이터 활용 정규화 |
| **Neural Collapse (2023)** | 손실 경관(loss landscape)을 균형 있게 유도 | 이론적 일반화 보장 |
| **Foundation Model Fine-tuning (2024~)** | 사전학습된 대형 모델 활용 | 멀티모달 사전지식 활용 |

2020년 이후에는 데이터 증강, 분리 학습(decoupled training), 손실 재균형(loss rebalancing), 대조 학습(contrastive learning) 등 다양한 관점에서 long-tailed 인식 문제를 해결하기 위한 방법들이 개발되고 있다.

모델 수준에서는 분리 프레임워크(decoupled framework)와 같은 방법이 불균형 영향을 줄이기 위해 특징 표현 학습과 분류기 최적화를 분리한다.

2단계 프레임워크는 long-tailed 학습에서 주요 아키텍처로 부상하였다. 첫 번째 단계에서 모델은 불균형 데이터로 학습되며, Mixup 등 다양한 증강 전략을 통해 표현 학습이 개선된다.

최근 대조 학습 접근법들은 모든 클래스에서 균일하게 판별적인 특징을 장려함으로써 long-tailed 인식에 유망한 결과를 보여주고 있다.

### 4-2. 앞으로 연구 시 고려할 점

#### ① 보조 분류기 배치 전략의 자동화
현재는 사람이 수동으로 보조 분류기의 부착 위치를 설정하지만, Neural Architecture Search(NAS)와 결합하여 최적 배치를 자동화하는 연구가 필요합니다.

#### ② Vision Transformer(ViT) 등 비CNN 아키텍처 확장
모델 수준의 방법들이 특징 표현 학습과 분류기 최적화를 분리하는 방향으로 발전하고 있으므로, 본 논문의 보조 분류기 방식을 Transformer 기반 모델에 통합하는 연구가 중요합니다.

#### ③ Foundation Model과의 결합
파운데이션 모델은 long-tailed 시각 인식에 근본적으로 다른 해법을 제공하며, 연구자들은 사전 학습 모델 내 풍부한 멀티모달 상식의 중요성을 점점 더 인식하고 있다. 본 논문의 앙상블 손실 전략을 대규모 사전학습 모델의 파인튜닝 단계에 적용하는 연구가 유망합니다.

#### ④ 소수 클래스의 일반화 보장
불균형 학습에서 소수 클래스는 손실 경관의 안장점(saddle point)으로 수렴하는 경향이 있으며, 이는 종종 일반화 저하로 이어진다. 이론적 일반화 보장을 위한 연구가 병행되어야 합니다.

#### ⑤ 다중 도메인 적용
딥러닝 방법의 약점 중 하나는 고도로 불균형한 데이터를 처리하는 능력의 부재로, 일부 중요한 실세계 응용 분야에서 딥러닝의 활용을 제한한다. 의료 영상, 자율주행, 사기 탐지 등 실세계 불균형 도메인에 대한 광범위한 검증이 필요합니다.

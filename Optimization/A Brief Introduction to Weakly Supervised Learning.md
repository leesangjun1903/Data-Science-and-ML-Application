# A Brief Introduction to Weakly Supervised Learning

**Zhou, Zhi-Hua. *National Science Review*, 5: 44–53, 2018. doi: 10.1093/nsr/nwx106**

---

## 1. Executive Summary (10문장 이내)

완전한 지도학습(Supervised Learning)은 대량의 정확한 레이블 데이터를 필요로 하지만, 현실에서는 데이터 레이블링 비용이 매우 높아 강한 감독 정보를 확보하기 어렵다.  
본 논문은 이러한 현실적 제약을 극복하기 위해 **약지도 학습(Weakly Supervised Learning)**의 세 가지 핵심 유형을 체계적으로 정리한 리뷰 논문이다.  
세 가지 유형은 **(1) 불완전 감독(Incomplete Supervision)**, **(2) 부정확한 감독(Inexact Supervision)**, **(3) 오류가 있는 감독(Inaccurate Supervision)**으로 구분된다.  
불완전 감독은 레이블이 일부 데이터에만 존재하는 상황으로, 능동 학습(Active Learning)과 반지도 학습(Semi-supervised Learning)으로 대응한다.  
부정확한 감독은 세밀하지 않은 레이블만 존재하는 상황으로, 다중 인스턴스 학습(Multi-instance Learning)이 핵심 방법론이다.  
오류가 있는 감독은 레이블 자체에 잡음(noise)이 포함된 상황으로, 크라우드소싱(Crowdsourcing) 문제와 연결된다.  
각 유형에 대해 주요 알고리즘, 이론적 기반, 그리고 한계를 함께 논의한다. 저자는 실제 현장에서 세 유형이 동시에 발생하는 혼합 시나리오가 빈번함을 강조한다.  
본 논문은 포괄적 리뷰보다는 각 분야의 문헌 안내서(literature index)를 목표로 하며, 이진 분류(binary classification)를 중심으로 논의를 단순화한다.  
약지도 학습은 데이터 레이블링 비용 문제가 심화되는 현대 AI 환경에서 점점 더 중요해지고 있다.

### 1-1. 연구의 목적과 필요성

**목적:** 완전한 레이블 데이터 없이도 효과적인 예측 모델을 학습할 수 있는 약지도 학습 방법론들을 세 가지 유형으로 분류하고 체계적으로 소개한다.

**필요성:**
- 딥러닝 등 현대 지도학습 기법은 대규모 정확한 레이블 데이터를 전제로 성공하였으나 (p.44, Abstract)
- 현실에서는 **레이블링 비용**(인력·시간·전문성)이 매우 높아 완전한 레이블 데이터 확보가 어려움
- 이미지 분류, 의료 진단, 약물 활성 예측 등 실제 응용 분야에서 레이블 부재/불완전/오류 문제가 빈번하게 발생 (p.44, Introduction)
- 따라서 약한 감독 정보(weak supervision)만으로도 좋은 모델을 학습하는 방법론 연구가 필수적

> 💡 **용어 설명**
> - **지도학습(Supervised Learning):** 입력 데이터와 그에 대응하는 정답 레이블(label)을 쌍으로 제공하여 모델을 학습시키는 방법
> - **레이블(Label):** 각 데이터 샘플이 속하는 클래스 또는 정답 값
> - **딥러닝(Deep Learning):** 여러 층의 신경망을 이용해 데이터로부터 특징을 자동 학습하는 기계학습 방법

### 2-1. 해결하고자 하는 문제, 제안 방법, 모델 구조, 성능 및 한계

#### 🔷 (A) 불완전 감독 (Incomplete Supervision)

**해결 문제:** 레이블 데이터가 소수이고 대량의 비레이블 데이터가 존재할 때, 어떻게 좋은 예측 모델을 학습하는가? (p.45)

**형식 정의:**

$$D = \{(\boldsymbol{x}_1, y_1), \ldots, (\boldsymbol{x}_l, y_l), \boldsymbol{x}_{l+1}, \ldots, \boldsymbol{x}_m\}$$

- $\boldsymbol{x}_i \in \mathcal{X}$: 입력 특징 벡터 (feature vector)
- $y_i \in \mathcal{Y} = \{Y, N\}$: 레이블 (이진 분류 기준)
- $l$: 레이블이 있는 데이터 수
- $u = m - l$: 레이블이 없는 데이터 수
- $m$: 전체 훈련 데이터 수

**제안 방법 1: 반지도 학습 - 가우시안 혼합 모델 기반** (p.47)

$$f(\boldsymbol{x} | \Theta) = \sum_{j=1}^{n} \alpha_j f(\boldsymbol{x} | \theta_j)$$

- $\alpha_j$: $j$번째 혼합 성분의 혼합 계수 (mixture coefficient), $\sum_{i=1}^{n} \alpha_i = 1$
- $\theta_j$: $j$번째 혼합 성분의 모델 파라미터
- $\Theta = \{\theta_i\}$: 전체 모델 파라미터 집합
- $n$: 혼합 성분의 수

최대 사후 확률(MAP) 기준의 분류 모델:

$$h(\boldsymbol{x}) = \arg\max_{c \in \{Y,N\}} \sum_{j=1}^{n} P(y_i = c | g_i = j, \boldsymbol{x}_i) \times P(g_i = j | \boldsymbol{x}_i)$$

- $c$: 예측 클래스 ($Y$ 또는 $N$)
- $g_i$: $i$번째 샘플이 속한 혼합 성분 인덱스 (잠재 변수)
- $P(y_i = c | g_i = j, \boldsymbol{x}_i)$: 성분 $j$와 특징 벡터 $\boldsymbol{x}_i$ 주어질 때 클래스 $c$의 조건부 확률 → **레이블 정보 필요**
- $P(g_i = j | \boldsymbol{x}_i)$: 사후 성분 확률 → **비레이블 데이터로 추정 가능**

$$P(g_i = j | \boldsymbol{x}_i) = \frac{\alpha_j f(\boldsymbol{x}_i | \theta_j)}{\sum_{k=1}^{n} \alpha_k f(\boldsymbol{x}_i | \theta_k)}$$

- 분자 $\alpha_j f(\boldsymbol{x}_i | \theta_j)$: 성분 $j$의 사전 확률 × 성분 $j$에서의 가능도
- 분모: 정규화 상수 (모든 성분에 대한 가중 가능도 합)

> 💡 **용어 설명**
> - **가우시안 혼합 모델(Gaussian Mixture Model, GMM):** 데이터가 여러 개의 가우시안(정규) 분포의 혼합으로 생성된다고 가정하는 확률 모델
> - **MAP(Maximum A Posteriori):** 사전 확률과 가능도를 결합하여 사후 확률을 최대화하는 추정 방법
> - **EM 알고리즘:** 잠재 변수가 있는 모델에서 반복적으로 기댓값(E-step)과 최대화(M-step)를 교차 수행하여 최대가능도 추정을 하는 알고리즘

**제안 방법 2: 능동 학습 (Active Learning)** (p.45–46)
- 선택 기준: **정보성(Informativeness)** + **대표성(Representativeness)**
- 불확실성 샘플링(Uncertainty Sampling): 학습기가 가장 낮은 신뢰도를 보이는 비레이블 인스턴스 쿼리
- 쿼리-바이-커미티(Query-by-Committee): 여러 학습기 간 불일치가 가장 큰 인스턴스 쿼리

**모델 구조:**

```
[소수 레이블 데이터 + 대량 비레이블 데이터]
          ↓
  [능동학습] → Oracle(전문가)에게 쿼리 → 레이블 획득
  [반지도학습] → 비레이블 데이터의 분포 구조 활용
  [전이적 학습] → 비레이블 데이터 = 테스트 데이터 (closed-world)
          ↓
      [예측 모델]
```

**성능 향상:**
- 실현 가능(realizable) 케이스: 능동 학습으로 샘플 복잡도의 **지수적 개선** 가능 [13, 14] (p.46)
- Tsybakov 잡음 모델 가정 시 유계 잡음에서도 지수적 개선 [16, 17]

**한계:**
- 정보성 기반: 초기 레이블 데이터 부족 시 초기 모델 불안정 (p.46)
- 대표성 기반: 클러스터링 결과에 성능이 과도하게 의존 (p.46)
- 반지도 학습: 비레이블 데이터 활용이 오히려 성능 저하를 유발할 수 있음 [36, 37] (p.48)
- 그래프 기반 방법: $O(m^2)$ 저장공간, $O(m^3)$ 연산 복잡도 → 확장성 문제 (p.47)

> 💡 **용어 설명**
> - **샘플 복잡도(Sample Complexity):** 목표 성능을 달성하기 위해 필요한 최소 훈련 샘플의 수
> - **Tsybakov 잡음 모델:** 결정 경계 근방에서의 잡음 분포에 대한 특정 가정을 도입한 잡음 모델. 기계 학습 및 통계적 학습 이론(Statistical Learning Theory)에서 이진 분류(Binary Classification) 문제의 난이도를 제약하기 위해 사용하는 핵심적인 마진 조건(Margin Condition)입니다. 
> - **전이적 학습(Transductive Learning):** 테스트 데이터가 학습 시 이미 알려져 있다고 가정하고, 그 데이터에 대해 예측을 최적화하는 학습 방식

#### 🔷 (B) 부정확한 감독 (Inexact Supervision) — 다중 인스턴스 학습 (p.48–49)

**해결 문제:** 개별 인스턴스 레이블 없이 **백(bag) 수준**의 레이블만 존재할 때, 어떻게 예측 모델을 학습하는가?

**형식 정의:**

$$D = \{(X_1, y_1), \ldots, (X_m, y_m)\}$$

$$X_i = \{\boldsymbol{x}_{i1}, \ldots, \boldsymbol{x}_{i,m_i}\} \subseteq \mathcal{X}$$

- $X_i$: $i$번째 **백(bag)** — 여러 인스턴스의 집합
- $\boldsymbol{x}_{ij} \in \mathcal{X}$: $i$번째 백의 $j$번째 인스턴스 ($j \in \{1, \ldots, m_i\}$)
- $m_i$: $i$번째 백 내 인스턴스 수
- $y_i \in \mathcal{Y} = \{Y, N\}$: 백 레이블
- **양성 백(Positive Bag):** $y_i = Y$이면, $\exists \boldsymbol{x}_{ip}$ (양성 인스턴스)가 존재 ($p$는 미지)
- **음성 백(Negative Bag):** $y_i = N$이면, 모든 인스턴스가 음성

**알고리즘 패러다임 3가지:**

| 패러다임 | 설명 |
|---------|------|
| 인스턴스-공간(Instance-space) | 인스턴스 수준 응답을 집계하여 백 레이블 예측 |
| 백-공간(Bag-space) | 백 전체를 하나의 단위로 처리 |
| 임베딩-공간(Embedded-space) | 임베딩된 특징 공간에서 학습 수행 |

**모델 구조:**
- 이미지 → 패치(patch) 추출 → 백(bag) 구성 → MIL 분류기 학습
- Figure 5: Single Blob(SB) — 16인스턴스/이미지, Single Blob with Neighbors(SBN) — 9인스턴스/이미지

**성능 향상:**
- 약물 활성 예측, 이미지 분류/검색, 텍스트 분류, 스팸 탐지, 의료 진단 등 다양한 분야에서 효과적 (p.48)
- 단순 밀집 샘플링 백 생성기가 복잡한 것보다 우수한 성능 [59] (p.49)

**한계:**
- 백 생성 방식에 성능이 크게 좌우됨 (p.49)
- 이론적 분석 결과가 매우 희소 (p.49)
- 이질적(heterogeneous) 케이스에서 학습이 매우 어려움 [64–66]

> 💡 **용어 설명**
> - **백(Bag):** 다중 인스턴스 학습에서 여러 인스턴스를 묶은 집합 단위. 예: 하나의 이미지(백)는 여러 패치(인스턴스)로 구성됨
> - **키 인스턴스(Key Instance):** 양성 백을 양성으로 만드는 핵심 인스턴스
> - **이질적(Heterogeneous) 케이스:** 백 내 각 인스턴스가 서로 다른 규칙으로 분류되는 경우

#### 🔷 (C) 오류 있는 감독 (Inaccurate Supervision) (p.49–50)

**해결 문제:** 훈련 데이터의 레이블에 오류(잡음)가 포함된 경우 어떻게 신뢰할 수 있는 모델을 학습하는가?

**주요 방법론:**
1. **데이터 편집법 (Data Editing):** 상대 이웃 그래프(relative neighborhood graph) 구성 → 절단 간선(cut-edge) 가중치로 의심 인스턴스 탐지 → 제거 또는 재레이블링 (p.49, Figure 6)
2. **크라우드소싱 기반 학습:**
   - 다수결 투표 (Majority Voting)
   - EM 알고리즘 기반 확률적 모델 [77, 78]
   - 미니맥스 엔트로피(minimax entropy) 원리 [35]

**크라우드소싱 비용 이론:**
- 효과적 크라우드소싱 학습에 필요한 최소 크라우드 레이블 수의 상한 제시 [83] (p.50)
- Dawid-Skene 모델 [88]: 작업자별 오류율을 EM으로 추정

**한계:**
- 이웃 기반 방법은 **고차원 데이터**에서 신뢰도 저하 (p.49–50)
- 대부분의 연구가 Dawid-Skene 모델의 단순화 가정(모든 태스크의 잠재 비용 동일)에 의존 (p.50)
- 스패머/적대적 작업자 처리 전략이 아직 제한적 (p.50)

> 💡 **용어 설명**
> - **레이블 잡음(Label Noise):** 훈련 데이터의 레이블이 실제 정답과 다르게 기록된 오류
> - **크라우드소싱(Crowdsourcing):** 불특정 다수의 사람들에게 작업을 분산하여 처리하는 방식. Amazon Mechanical Turk(AMT)가 대표적
> - **미니맥스 엔트로피(Minimax Entropy):** 최악의 경우 성능을 최소화하는 방향으로 최적화하는 원리
> - **Dawid-Skene 모델:** 각 작업자의 오류율을 잠재 변수로 모델링하여 진짜 레이블을 추정하는 확률 모델

### Figure 2 (p.46) — 능동 학습 vs. 반지도 학습 vs. 전이적 학습

**내용:** 세 가지 불완전 감독 학습 방법의 데이터 흐름과 테스트 데이터 처리 방식 차이를 도식화

**해석:**
- **능동 학습:** 비레이블 데이터 중 선택적으로 Oracle에게 쿼리 → 레이블 획득 후 훈련

- **핵심 통찰:** 테스트 데이터의 가용성(availability) 가정이 세 접근법을 구분하는 핵심 기준

> 💡 **용어 설명**
> - **Oracle:** 능동 학습에서 쿼리된 인스턴스에 대해 정확한 레이블을 제공하는 전문가 또는 자동 시스템
> - **Closed-world 가정:** 예측해야 할 테스트 데이터가 학습 시 이미 알려져 있다는 가정

### Figure 3 (p.47) — 비레이블 데이터의 유용성

**내용:** 레이블 데이터만으로는 테스트 포인트 예측 불가 → 비레이블 데이터 관측 시 명확한 예측 가능

### Figure 4 (p.48) — SVM vs. S3VM 결정 경계 비교

**내용:** 레이블 데이터(+/-)만 사용한 SVM과, 비레이블(회색) 데이터도 활용한 S3VM의 결정 경계 차이

**해석:**

> - **SVM(Support Vector Machine):** 두 클래스 사이의 마진(margin)을 최대화하는 결정 경계를 찾는 분류 알고리즘
> - **S3VM(Semi-supervised SVM):** 비레이블 데이터도 활용하여 저밀도 영역에 결정 경계를 위치시키는 SVM의 확장

## 8. 결론: 시사점, 후속 연구, 추가 방향

### 8-1. 저자 제시 시사점

1. **약지도 학습의 보편적 중요성:** 데이터 레이블링 비용 문제가 어떤 분야에서든 존재하므로, 약지도 학습은 범용적으로 필요 (p.50)
2. **혼합 시나리오 연구 필요성:** 세 유형이 동시에 발생하는 현실 상황에 대한 통합 방법론 연구 필요 (p.50, [52, 92, 93])
3. **다중 클래스/다중 레이블로의 확장:** 이진 분류 너머의 복잡한 과제에서 약지도 학습 연구 확대 필요 (p.50–51)
4. **시간 지연 감독:** 강화학습과의 연결을 통한 시간 지연 약지도 학습 탐구 (p.50)
5. **이론적 기반 강화:** 특히 MIL(다중 인스턴스 학습)의 이론적 분석이 매우 부족함을 지적 (p.49)

- 안전한(safe) 반지도 학습을 위한 앙상블 기반 최악 케이스 최적화 [37]

### 8-1. 모델의 일반화 성능 향상 가능성 (중점 분석)

본 논문에서 일반화 성능과 직결된 핵심 내용:

**① 안전한 반지도 학습(Safe Semi-supervised Learning)** (p.48, [37])
- 비레이블 데이터 활용이 항상 성능 향상을 보장하지 않음
- 앙상블 메커니즘으로 최악 케이스 성능을 최적화하는 전략이 일반화 성능 향상의 핵심
- **수식적 함의:**

$$\theta^* = \arg\min_{\theta} \max_{P \in \mathcal{P}} \mathbb{E}_{(x,y) \sim P}[\mathcal{L}(h_\theta(x), y)]$$

- $\theta^*$: 최적 모델 파라미터
- $\mathcal{P}$: 가능한 데이터 분포의 집합 (불확실한 분포 공간)
- $\mathcal{L}$: 손실 함수
- 이는 최악 분포에서의 손실을 최소화하는 **minimax 최적화** 관점

**② 클러스터 가정과 매니폴드 가정** (p.47)
- 반지도 학습의 일반화를 위한 두 핵심 귀납적 편향(inductive bias)
- **클러스터 가정:** 같은 클러스터 내 인스턴스 → 같은 레이블 → 클러스터 경계에 결정 경계 위치
- **매니폴드 가정:** 데이터가 저차원 매니폴드에 분포 → 인접 인스턴스가 유사 예측을 가져야 함

**③ 이론적 일반화 조건** (p.46, [13–18])
- 능동 학습: 지수적 샘플 복잡도 개선 → 적은 레이블로 동등한 일반화 성능 달성 가능
- Tsybakov 잡음 모델 하에서도 일반화 성능 보장 가능성 확인

**추가 후속 연구 방향 (일반화 성능 중심):**

| 방향 | 설명 |
|------|------|
| 분포 이동(Distribution Shift) 강건성 | 훈련-테스트 분포 불일치 시에도 일반화 가능한 약지도 학습 이론 개발 |
| PAC-Bayes 프레임워크 적용 | 약지도 설정에서의 일반화 오차 상한 이론적 도출 |
| 메타 학습(Meta-Learning) 결합 | 적은 레이블로 새로운 과제에 빠르게 적응하는 few-shot 약지도 학습 |
| 도메인 적응(Domain Adaptation) 결합 | 소스 도메인의 약한 레이블로 타깃 도메인 일반화 |

> 💡 **용어 설명**
> - **귀납적 편향(Inductive Bias):** 학습 알고리즘이 훈련 데이터 이외의 데이터에 대해 일반화하기 위해 가정하는 선험적 가정
> - **PAC(Probably Approximately Correct):** 높은 확률로 근사적으로 정확한 가설을 학습할 수 있다는 이론적 학습 프레임워크
> - **분포 이동(Distribution Shift):** 훈련 데이터와 테스트 데이터의 통계적 분포가 다른 현상

### 8-2. 2020년 이후 최신 연구 비교 분석

> ⚠️ **주의:** 아래 2020년 이후 연구 비교는 제 학습 데이터(2024년 1월 기준)에 기반한 내용이며, 일부 세부 수치의 정확성은 100% 보장되지 않습니다. 반드시 원문 논문을 직접 확인하시기 바랍니다.

#### 불완전 감독 분야 최신 동향

| 연구 | 핵심 기여 | 본 논문과의 연결 |
|------|----------|----------------|
| **FixMatch** (Sohn et al., 2020, NeurIPS) | 신뢰도 높은 예측에 대한 의사 레이블(pseudo-label) + 강한 데이터 증강 결합 | co-training의 의사 레이블 아이디어를 딥러닝에 확장 |
| **SimCLR / MoCo** (2020–2021) | 대조 학습(contrastive learning)으로 비레이블 데이터에서 표현 학습 | 반지도 학습의 비레이블 활용 아이디어를 자기지도 학습으로 발전 |
| **FlexMatch** (Zhang et al., 2021, NeurIPS) | 클래스별 적응적 임계값으로 커리큘럼 의사 레이블링 | 불확실성 샘플링의 동적 임계값 개념 확장 |

> 💡 **용어 설명**
> - **의사 레이블(Pseudo-label):** 모델이 예측한 레이블을 마치 진짜 레이블처럼 사용하는 자기 학습(self-training) 기법
> - **대조 학습(Contrastive Learning):** 같은 데이터의 다른 증강(augmentation) 버전은 유사하게, 다른 데이터와는 다르게 표현을 학습하는 자기지도 학습 방법

#### 부정확한 감독 분야 최신 동향

| 연구 | 핵심 기여 | 본 논문과의 연결 |
|------|----------|----------------|
| **DSMIL** (Li et al., 2021, CVPR) | 자기 주의(self-attention) 기반 MIL로 병리 이미지 분류 | MIL의 딥러닝 결합 및 key instance 탐지 |
| **TransMIL** (Shao et al., 2021, NeurIPS) | Transformer 기반 MIL로 인스턴스 간 관계 모델링 | 인스턴스 독립성 가정을 완화하는 방향 [46,47] |
| **약지도 객체 탐지(WSOD)** (다수) | 이미지 수준 레이블로 객체 위치 탐지 | MIL의 key instance 탐지 응용 확장 |

> 💡 **용어 설명**
> - **자기 주의(Self-attention):** Transformer 구조에서 입력 시퀀스의 각 요소가 다른 모든 요소와의 관계를 계산하는 메커니즘
> - **WSOD(Weakly Supervised Object Detection):** 바운딩 박스 레이블 없이 이미지 수준 레이블만으로 객체를 탐지하는 방법

#### 오류 있는 감독 분야 최신 동향

| 연구 | 핵심 기여 | 본 논문과의 연결 |
|------|----------|----------------|
| **DivideMix** (Li et al., 2020, ICLR) | 손실 분포로 깨끗한/잡음 샘플 구분 후 MixUp 반지도 학습 | 레이블 잡음 + 반지도 학습의 혼합 시나리오 |
| **CORES** (Cheng et al., 2021) | 신뢰 기반 샘플 선택으로 잡음 레이블 처리 | 데이터 편집 아이디어의 딥러닝 확장 |
| **LLM 기반 레이블링** (2022–2024) | GPT-4 등 LLM으로 크라우드소싱 대체 | 크라우드소싱의 비용-품질 트레이드오프 재정의 |

#### 본 논문이 미치는 영향과 앞으로의 고려사항

**본 논문의 영향:**

1. **분류 체계의 표준화:** 불완전/부정확/오류라는 3분류 체계가 이후 많은 연구에서 참조 프레임워크로 사용됨
2. **연구자 진입장벽 낮춤:** 약지도 학습의 폭넓은 연구 영역을 간결하게 정리하여 신진 연구자들의 초기 탐색 비용 절감
3. **혼합 시나리오 연구 촉진:** 혼합 약지도 학습의 중요성을 명시적으로 강조하여 후속 연구 방향 제시
4. **딥러닝 시대의 약지도 학습 재조명:** 딥러닝과 약지도 학습의 결합 연구(반지도 딥러닝, 약지도 탐지 등)의 이론적 배경으로 기능

**앞으로 연구 시 고려할 점:**

| 고려사항 | 내용 |
|---------|------|
| 🔑 **딥러닝과의 통합** | 본 논문의 방법론 대부분이 전통적 ML 기반 → 딥러닝 시대의 약지도 학습 이론 재정립 필요 |
| 🔑 **LLM 기반 약지도 학습** | GPT-4 등 LLM이 약한 레이블 생성자로 기능 → 크라우드소싱 패러다임 변화 대응 |
| 🔑 **혼합 약지도 시나리오** | 세 유형이 동시에 발생하는 실제 환경 대응 통합 프레임워크 개발 |
| 🔑 **공정성(Fairness) 문제** | 잡음 레이블이 특정 집단에 편향적으로 분포할 경우 모델 공정성 훼손 가능 |
| 🔑 **이론과 실제의 간극** | 이론적 보장이 실제 딥러닝 모델에서 성립하는지 검증 연구 필요 |
| 🔑 **연산 효율성** | 대규모 데이터에서 그래프 기반 방법의 $O(m^3)$ 문제 → 근사 알고리즘 개발 |
| 🔑 **분포 이동 강건성** | 약지도 학습 모델이 훈련-배포 환경 변화에 얼마나 강건한지 평가 기준 마련 |
